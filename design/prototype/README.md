## 覆盖范围

16 个界面族、55 项来源意图、F01–F07、M01–M12 的可操作本地样机：

| 族 | 入口 | 主要状态与行为 |
|---|---|---|
| S01 今天 | 学员今天 | 已安排/进行中/完成/休息/暂停/周期结束/未安排/内容不可用；继续/恢复/查看记录/现用计划/我的内容/收到计划/饮食自评 |
| S02 发现 | 学员发现 | 训练/饮食/教练；筛选、搜索、收藏、加载、失败、空、下架；内容完整摘要与详情入口 |
| S03 计划详情 | 发现 → 训练 | 训练日/完整动作、来源与适用、收藏/分享、成年与登录准入、替换影响、取消、下架、重复开始 |
| S04 训练执行 | 今天继续/开始 | 重量/次数/单侧/秒；真实休息计时、暂停、加时、跳过；待同步/失败、同组冲突、完成、无历史 |
| S05 记录 | 学员记录 | 4/8/12 周范围、动作口径、真实日期间距图表、kg/秒刻度、明细、反馈、空/单条/不足/补记 |
| S06 发现教练 | 发现 → 教练 | 目标/方式/价格筛选、空结果、比较字段、无评分、城市仅在需要线下时显示 |
| S07 教练详情 | 教练列表 | 人物/服务包/价格语境/响应/交付样例/咨询带入；渠道未核定；不收款 |
| S08 消息 | 学员或教练消息 | 列表/会话、当前人物与服务、咨询带入、引用、草稿、同 ID 重试、只读、撤权、关系待确认 |
| S09 收到计划 | 今天/消息 | 现用与新版本、完整内容、具体变化、采用影响、过期/冲突/无权限/已采用；只改未来 |

| S13 教练待办 | 教练待办 | 计数来自样例集合、按原因排序、接续草稿/学员/消息、已处理与恢复、空态 |

## 数据与边界

- 固定预览日期 `2026-10-24（周六）`，本周 `10月19日–25日`；训练日二/四/六；训练 12 组由同一数组生成。
- 学员林澈、教练顾言、周岚/安然/陈墨、教练江遥/何岸均为样例，不代表真实用户、认证、健康结论、服务成绩或成交。
- 服务确认与健康授权分开；未授权不显示健康正文。撤回健康授权会清除可见健康原文与摘要；普通安排交流保留。
- 先登录/年龄准入只在本机模拟，不接真实登录、短信、账号验证或服务端权限；未成年停止服务但可浏览；未知年龄不能通过换内容绕过。
- 计划替换只改未来；已完成/进行中会话在替换时归档为历史，未完成不伪称完成；同一次完成不重复计数。
- 教练计划按学员隔离（林澈/周岚），切换/刷新不串；发布只更新当前学员的交付，学员现用版本不自动改变。
- 服务价格 0–9999 整数；负数/空/非法输入保留原值并阻止保存；0 可明确作为免费。已确认约定保存名称/单位/周期/价格快照，不随新报价。
- 旧 localStorage 状态加载时按包补新增服务字段，并用已保存服务刷新公开投影；已知约定按服务版本从可信旧投影恢复，不猜当前报价。
- 预览控制（右上角「预览」）集中角色/情境/当前屏状态/减少动态/文字大小/重置；设计解释、内部编号和验收话术不进入产品正文。

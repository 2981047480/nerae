# Nerae

Nerae 是一个面向学员与教练的训练记录项目。本仓库包含 uni-app 客户端、Go 服务端、产品规格、设计记录和验证证据。当前为**开发中的候选版本**，并非可直接安装使用的正式产品。

## 当前进展

- 客户端正在实现训练后记录和每组完成后记录；两种模式共享训练记录，不设计训练或休息倒计时。
- 自由训练、训练组保存、跨设备冲突处理及邮箱登录已有代码或测试候选，真实邮箱登录、线上服务和双设备同步尚未完成端到端验收。
- 目标平台为 iOS、Android 和微信小程序。iOS 安装签名、Android 真机及小程序真机尚待验证。
- 正式视觉要求为白底、白灰黑色阶和浅灰细线；设计素材与组件实现仍需逐项核对。

请先阅读 [当前状态](docs/CURRENT_STATE.md)、[训练记录实施计划](docs/RECORDING_DELIVERY_PLAN.md) 和 [色彩规范](docs/design/MONOCHROME_COLOR_SYSTEM.md)。历史文档中的完成状态和测试结果应以其记录的版本与验证范围为准。

## 主要目录

- `apps/client/`：uni-app Vue 3 / TypeScript 客户端。
- `apps/api/`：Go 服务端、迁移和测试。
- `api/`、`packages/`：接口合同、生成类型及共享内容。
- `docs/`：产品规则、设计、任务与验证证据。

项目锁定的 Node 和 Go 版本分别见 `.node-version`、`.go-version`；包管理器版本见 `package.json`。首次构建需自行安装对应工具链及依赖。SDK、Apple / DCloud 签名资料、QQ SMTP 授权码、实际服务端配置均不包含在仓库中。

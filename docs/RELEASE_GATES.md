## L01 外部证据交付格式

业务负责人提供材料，合规角色复核，Lead 组织集成。每条证据记录：事项 ID、实际主体/类目/服务形态、权威来源/答复日期、原文材料位置、适用条件、结论/限制、责任人、有效期或复核触发、受控配置与验证脚本。不使用“通常如此”作为批准。

联系渠道专项必须包括：双方界面与实际入口；能否连接独立教练而非平台客服；用户主动授权的范围；通知拒绝/窗口过期/被拒绝/取消咨询；是否允许相关联系信息；失败时回站路径；平台外交易与平台确认关系如何衔接。渠道不可用时保持咨询记录，公开获客不开启。取得证据后先更新合同/流程再接入，不在客户端埋未经批准的隐藏出口。

留存专项必须分普通消息、健康内容、私有文件、账号日志、同意证明/法定留存、备份；写明撤回、结束、注销和恢复备份之后各自的访问限制、删除 SLA 与隔离要求。无批准配置时生产启动检查失败，不用默认永久保存。

## 最小申诉与投诉 SOP（O01/O02）

1. 入口随公开评价/教练服务同时可见；接收对象、理由和自愿证据，不索取不必要健康材料。生成工单号和预计处理日。
2. 指定当天负责人及替补，按工作日历计时。服务投诉 72 小时内响应；评价申诉 3 个工作日内处理，临界提前升级；时限是产品承诺，运营不足时不得先开功能再延后。
3. 审核者只获该工单必要数据，私有健康证据另审批；身份不同于当事人。记录查阅、决定、理由、通知与再次申诉入口。
4. 下架/恢复/更正都留审计，旧评分缓存与分享同步失效；严重风险按内容策略临时限制并说明，不以工单自动认定真实医疗风险或支付事实。
5. 初期可用受控人工台账，字段含工单 ID、关联资源版本、状态、负责人、截止时间、证据权限、决定、送达状态；不得放到无访问控制的共享表或聊天群。
6. 上线前演练一次正常、一次超时升级、一次误下架恢复、一次撤权证据不可读。证据为时间戳和受控记录，不是空模板。

## 试点统计（V04）

- 固定 cohort：首次有效使用日，来源 natural_plaza / free_template_conversion / coach_invite 互斥并保留首次归因；无法归因单列 unknown，不强补。
- D7：入组日后第7个当地日有核心使用的去重人数 / 已完成第7日观察的入组人数；D30 同理。另列区间留存时必须换名称，不能混用。
- 关系转化：具备观察窗的有效咨询发起学员中确认 active 关系的比例；成交自报单列，无支付验证就不报告真实 GMV。
- 续期：服务期已结束且经过事先固定续期观察窗的关系为分母；新有效服务说明双方确认才计续期，不以自动提醒或自报替代。
- 交付质量：草稿恢复成功、按期发布、训练同步成功、可恢复错误、回复等待、教练实际人工分钟数；注明设备/人群/样本与隐私限制。
- 以上阈值在试点启动前登记；小样本给区间与原始计数，不用平均值掩盖分组失败。外部审核和成熟观察窗都不能通过增加 agent 数量缩短。

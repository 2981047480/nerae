## 继续有效的行为与质量边界

- PRD 定义免费自助、教练选择与交付、AI 分层和不收款边界；APP_FLOW 定义用户任务、日期、保存恢复、发布与关系规则。
- 浏览不被完整资料录入阻断；已知资料带入；重要判断与授权保留明确确认；返回不丢上下文。
- 已确认记录、待同步、失败、信息不足、AI 草稿、未授权、只读等据实表达，颜色不能是唯一状态线索。
- 可读性、对比、触达、焦点、键盘、文本放大、窄屏和减少动态效果是后续必须验证的质量条件，不代表已接受任何旧字号、间距、圆角、色值或组件形态。
- 训练、探索、教练审阅和交流有不同的信息与注意力需求。不得用一套页面模板推导整款产品，也不把无溢出、可点击等技术检查等同用户喜欢。

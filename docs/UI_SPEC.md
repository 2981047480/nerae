# Nerae UI 规格状态

2026-10-27 · 当前方向为第五轮「个人训练工作室」，见 [R05](design/round-05/BRIEF.md)。用户对 App 全流程图表示“感觉还 OK”，并选择微信小程序与 iOS / Android App 同步交付；这表示方向可继续细化，不等于每屏已最终验收。R04 记录语义继续生效，旧视觉证据仅为历史。

- 默认训练后记录，可切换每组完成后记录；同一会话、组和输入，不存在训练/休息计时器。
- 当前采用墨石深色主题区、瓷白内容区与熔橙主要操作，系统字体；三套旧配色退出试览。外观存储独立于训练数据，旧外观 ID 回退至当前方向。当前颜色是 Lead 实现候选，尚非用户确认品牌。
- 首页并置本次记录、教练已有点评与待看计划，随后呈现训练积累、饮食与免费内容；手机优先露出教练跟进。数据来自原有明细，不推断训练完成。
- 发现以图片、内容主题、完整安排入口组织免费训练/饮食；教练卡并置同一服务的交付与报价。教练详情把具体交付、服务选择、完整样例和咨询上下文串联，当前服务约定快照不被新报价改写。
- 记录页汇总来自选定日期范围与实际组；图表保留单位与来源，不声称疗效或虚构进步。内容详情与发现保持图片/标题衔接；照片仅示意内容，不冒充教练本人或场地。
- 其余模块延续有效交互并继承颜色，保留授权、版本、AI 确认与服务边界。D02 把 R05 逐项转为三端可实施组件和状态规格；各端系统导航、键盘、安全区和平台能力分别验证。
- 保存/草稿/失败据实表达；实际重量次数只由用户填写或明确沿用参考。训练日期与录入时间分离。
- 账号关联与注销由 U08 承接：用户可找到入口、确认本人操作、查看处理中/完成/失败并恢复；会话失效与数据删除分别由 A01/O03 执行。D02 需补齐三端对应状态及参考，现阶段没有把该界面设计或实现标为完成。
- D02 在本文件建立页面、状态、素材和参考图到实际实施规格的索引；U01–U08 细拆执行卡时引用对应 D02 产物，并以实际三端截图验收。
- 当前是 Vue 独立本地样机，正式 uni-app/Go、微信真机和供应商均未实现或未验收。
- 本轮验证见 [验证记录](design/round-05/VERIFICATION.md)。技术检查不能代替用户对审美的判断或真实付费验证，未把旧任务自动改为新轮次 accepted。

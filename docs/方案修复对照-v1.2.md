## 1. 结论与责任边界

内部可处理的设计断点已补入当前 PRD v1.10、ER v1.2、OpenAPI v1.2.0、APP_FLOW 与任务计划。外部条件保留为明确门槛：用户已确认主体、类目与联系渠道尚未注册或核定，作为上线前置任务，不阻塞本轮规划交付，也不视为核定通过。

| 发现 | 本轮修正与位置 | 实施/外部剩余工作 |
|---|---|---|
| R01 动作无完整读模型 | `ExerciseSnapshot` 冻结名称/说明/注意事项/替代；新增动作目录与版本详情；写入拒绝伪造快照 | A03 真实内容、历史投影与客户端展示 |
| R02 教练草稿无法恢复 | 草稿 GET/列表返回编辑状态与版本；学员详情具名投影，隐藏未授权资料 | A03/A07 跨设备恢复、publishedVersion 与逐字段授权 |
| R03 今日/日历/漏练语义缺失 | 内容与执行安排分开；当前选择 CAS、安排版本、occurrence；固定日历、暂停/改期/漏练不顺延，历史不重算；APP_FLOW F02 | A04 日期/时区/重试/并发/恢复测试 |

[AGENT_ORG](AGENT_ORG.md) 定义原生子代理、每任务 worktree、共享合同单 owner、独立 review、串行集成与合并后重测。计划工具只检查/输出，不自动分发、合并或修改状态。本轮没有实际多 agent 并行试运行，不能声称已经达到 Cursor 的运行效率或完整功能对等；首次试运行建议在基础工程完成后选 A06+A08，测量冲突、返工和集成耗时。

## 4. 现在可复跑

从项目根目录执行；解释器需 Python 3.11+，依赖安装说明见 [测试 README](../api/tests/README.md)。

```sh
PYTHONDONTWRITEBYTECODE=1 api/tests/.venv-py311/bin/python api/tests/run_contract_tests.py --summary
api/tests/.venv-py311/bin/python scripts/plan.py check
api/tests/.venv-py311/bin/python -m unittest discover -s scripts/tests -v
api/tests/.venv-py311/bin/python scripts/plan.py ready
api/tests/.venv-py311/bin/python scripts/plan.py packet F01
npx --yes @redocly/cli@1.34.3 lint api/openapi.yaml
```

任务包里的 `make ...` 是未来 F01/F02 要建立的验证接口，目前不可当作已有 CI。上线必须另过 [RELEASE_GATES](RELEASE_GATES.md)；真实 HTTP/数据库/并发、供应商评测、专业内容审查、资格与渠道证据、真机、运维演练与成熟观察窗均未完成。

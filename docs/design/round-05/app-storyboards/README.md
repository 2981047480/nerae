## 主要边界

- 默认训练后记录，可选每组完成后记录，空白组不计入实际；无播放器、训练时钟、组间倒计时。
- 免费训练/饮食内容、教练独立报价；咨询不建关系、不授予健康访问；服务约定与内容授权分开，平台内不收款。
- 饮食为自评；AI 在现有模板内建议，用户/教练核对后采用/发布；新计划不自动覆盖既有安排或历史。
- 陌生联系渠道仍需核定；图像不证明该门槛、真实服务履约或转化已经通过。相邻图为流程与状态示例，部分示例日程并非同一份版本快照。

## 生成与检查

5 张使用内置 image_gen，完整生成提示词及局部修订提示词保存在 prompts.json。记录图的图像修订连续返回连接 403，停止该路径后改用可编辑 HTML 按同一视觉规则直接渲染；03-recording.source.html 是所选记录图的来源，保存了浏览器截图，未使用 CLI 模型或 Python 改图。

逐张查看了主标题、记录模式、无计时约束、服务与权限边界，并修正预览按钮、报价、日期、采集目的和撤权说明。记录图检查了两种方式的相同输入、空白组、6 组保存结果、单动作 kg 图表及列表/底部导航无重叠。其余生成图中的小字、部分装饰图标和示例日程仍需在实现时按规范细化；不把生成图当成最终合同文案。

最终图片通过格式解码检查，清单绑定像素尺寸与 SHA-256；Zip 进行 CRC 检查。主样机 src 与上一轮清单逐项一致，本轮没有改业务实现或重跑代码测试。生成图没有被提升为新的正式视觉接受或 U 卡状态。

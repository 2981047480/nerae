# D02 · 三端状态、返回与授权恢复矩阵

这是实现与验收输入，不是已完成的三端界面或设备测试。用户任务、数据和授权以 PRD / APP_FLOW 为准；身份方式与注销进度合同分别等 K01-02 / K01-03 接受后接线。遇到未确定能力显示明确不可用状态，不能模拟成功。相关视觉参考为 [30 屏索引](screen-map.md)，账号操作无对应完整画板。

## 关键任务的三端差异

| 场景 | 微信小程序 | iOS App | Android App | 共同结果 / 验收 |
|---|---|---|---|---|
| 首页进入账户与安全 | 顶部账户入口不进入胶囊占用区域；系统返回回到原页面 | 顶部账户入口避开状态栏及安全区；返回手势回原页面 | 顶部账户入口避开状态栏；系统返回回原页面 | 学员“今天”和教练工作台均可找到；入口有可读名称，不依赖头像辨认 |
| 按需登录或身份验证 | 使用 K01-02 选定且实际可用的方式；关闭平台弹层不等于成功 | 同左；外部授权返回后重新读取服务端结果 | 同左；系统返回或外部授权中断后保留原任务 | 登录完成回原任务；取消/失败不自动提交草稿；跨主体草稿不可串用 |
| 关联账号：发起、等待、确认 | 平台跳转和返回走适配层；失效或用户取消时显示可恢复状态 | 外部身份验证返回后刷新状态；中断可退回 | 后台恢复或系统返回后刷新状态；中断可退回 | 显示当前主体与服务端真实状态；冲突不合并账户；是否有对端确认由合同决定 |
| 注销：说明、确认、提交 | 输入及确认不被软键盘或胶囊遮挡；返回仅在提交前退出 | 软键盘、home indicator 与返回手势不覆盖确认 | 软键盘、手势导航和系统返回不覆盖确认 | 明确当前账号及影响；本人确认，重复提交不生成新请求；提交后仅在合同允许时取消 |
| 注销：处理中/会话失效 | 前后台切换后重新获取经授权状态 | 外部验证或重启后重新获取经授权状态 | 重启或系统回收后重新获取经授权状态 | 查询路径由 K01-03 定义；无安全查询能力时展示“暂无法确认”，不泄露状态、不冒称完成 |
| 注销：离线或提交结果未知 | 无网络时保留说明并提示联网；请求发出后断线显示结果未知 | 同左；系统中断后不可猜测是否提交 | 同左；返回或重启后不可猜测是否提交 | 离线未发送时不称已提交；不自动代用户提交。结果未知时联网后先按 K01-03 安全查询/幂等重试；仅本机退出与注销分开呈现 |
| 训练记录：批量或逐组输入 | 键盘出现时可滚到当前字段及保存动作；返回前保留草稿 | 键盘及 home indicator 不盖输入、单位和保存；侧滑返回保留草稿 | 键盘与系统返回/手势区不盖输入和保存；返回保留草稿 | 两模式同一会话与组键；半行提示，空白不计；切换不新增训练或计时器 |
| 断网、切账号、恢复 | 重新进入小程序先确认主体，再处理该主体队列 | 前后台/重启后先确认主体，再处理队列 | 系统回收/重启后先确认主体，再处理队列 | 已缓存且有效的计划快照可按合同本地记录并标待同步；未缓存内容明确不可用，不伪造计划；不同账号隔离草稿与队列；版本冲突保留输入并交用户处理 |
| 授权或采集同意撤回 | 取得结果后更新当前页，重新进入时重新校验 | 同左；系统通知点击后重新鉴权 | 同左；系统通知点击后重新鉴权 | 按下方规则阻止后续读取/处理；采集同意与教练共享授权分开 |

### 布局、键盘与焦点

- 页头、按钮区、键盘可见区域取各端实际安全区与键盘信息，不用一套固定像素猜系统区域；被遮挡的当前输入要滚入可见范围，错误提示与单位仍可读。键盘收起时不丢输入，不把暂存误报为服务器保存。
- 长文和 200% 文字下确认说明及主/次动作可滚动、顺序不反转；弹层关闭后焦点回原触发处。屏幕阅读能辨认当前模式、错误和处理状态，不只靠颜色区分。
- 在登录、关联、注销确认及记录输入各检查：顶部控件、焦点字段、错误、主操作、键盘开关、系统返回/手势、前后台和重启。设备/系统/微信版本、字号、截图或录屏及同一集成版本由对应 U 任务记录；不能用 H5 截图替代。

## 撤权和恢复：事实与系统动作

| 事件 | 用户可见状态与 App 行为 | 服务端和待验收边界 |
|---|---|---|
| 学员发起撤回但尚未得到服务端确认 | 显示“正在撤回”或失败/待重试；当前端暂停相关新提交，不显示“已撤回” | 远端撤权是否生效只以服务端确认结果为准；不能把离线点击当服务端已执行 |
| 服务端确认撤回教练某范围 | 该范围在当前已打开页及后续进入时显示无权占位；保留与此无关的普通内容和学员自己的记录 | 自确认时起阻止被撤范围的后续读取、模型输入和通知；已排队任务提交前重新检查授权，不把缓存当权限 |
| 教练端离线或无法确认最新授权 | 对受共享授权控制的健康内容不重新展示旧缓存，说明“暂无法验证访问权限”；普通且有权内容不随意清空 | 离线设备不能即时收到远端撤权，无法抹去此前已看过或已截取的信息；恢复连接后再查服务端并更新页面 |
| 涉及被撤范围的待发送/待同步内容 | 停止自动重放受影响项；提示需重新核验，不能把失败显示为成功；个人记录队列按本人主体和资源隔离 | 服务端在使用和提交时重查授权与版本；不得因其他教练权限失效删除学员本人的记录 |
| 消息和通知 | 不在通知预览放健康正文；点击时重新鉴权；已撤权的健康消息/附件显示无权占位 | 不承诺撤回已送达的系统通知；普通历史可见性按已批准留存配置和实际权限处理 |
| 切账号、重登、备份恢复 | 不展示或同步上一主体的私有缓存；重新确认当前主体及权限后才能恢复对应操作 | 缓存隔离与服务端授权并行；删除/留存及备份恢复限制由 O03/L01-03 实证，本规格不承诺清除离线设备的所有副本 |

撤回采集同意与撤回教练共享授权是两个独立结果：前者阻止该用途继续采集/处理，后者改变特定关系的共享范围；均按实际合同处理，不以一个按钮暗示两者都已发生。已发送给外部供应商的数据与已交付通知无法靠本页面回收，其处理与留存由已核定条款和运维流程约束。

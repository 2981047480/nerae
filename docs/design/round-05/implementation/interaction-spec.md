# D02 · 跨端交互和组件规格

状态：实施草案；正式视觉与三端真机尚未验收。[30 屏索引](screen-map.md)可用于对齐用户任务。2026-11-14 用户已选择白底、白灰黑和浅灰细边框，当前色彩以[色彩系统](../../MONOCHROME_COLOR_SYSTEM.md)为依据；R05 的颜色仅是历史样机。若示意图的小字、价格、图片或旧记录行为与最新用户决定、PRD / APP_FLOW 及有效合同冲突，须先收敛，不能直接照旧稿实施。

## 基础视觉与组件

历史本地样机值仍可在 `design/prototype/src/state/palette.ts` 和 `styles/tokens.css` 找到，包括橙色主操作与系统无衬线；这些是旧实现事实，不是新页面配色依据。新灰阶候选、语义角色及对比度验证见[色彩系统](../../MONOCHROME_COLOR_SYSTEM.md)。U01 需在小程序/iOS/Android 上按实际对比度、动态字号和平台限制检查，再由单一 owner 固化 token 并处理旧外观存储，禁止三端各自猜颜色；代码尚未因本文更新。

| 组件 | 需要表达 | 必要状态与行为 |
|---|---|---|
| 页框和导航 | 一屏一个清楚的主操作，保留系统安全区 | 返回、当前页面、长标题折行；系统返回不丢草稿；小程序胶囊、iOS home indicator、Android 手势区分别验证 |
| 主/次按钮 | 文案说清结果，例如保存、重试、核对并确认 | 正常、按下、禁用及原因、处理中、防重复；状态不能只靠颜色；危险动作独立确认 |
| 表单和记录组 | 用户输入 actual 值；标签、单位及错误就近显示 | 空白、半行、错误、已记录、待同步、失败；数字键盘不遮挡输入和提交；历史预填、复制、按计划应用及整次完成按最新记录决定处理，计划范围不伪装成确切实际次数 |
| 底部固定动作区 / 弹层 | 当前任务所需主操作和明确取消 | 安全区与软键盘出现时不遮挡；可滚动；系统返回/点关闭保留未提交输入；无障碍焦点可返回触发处 |
| 内容/服务卡 | 同一对象的名称、来源、可用状态、交付和报价 | 图片失败有可读回退；服务包更新不改已确认快照；权限未获核定时不显示假联系成功 |
| 提示和空状态 | 说清发生了什么、数据在哪里以及可做什么 | 加载、空、权限不足、失败、离线、已保存/待同步、412；不能用空白/零值冒充缺失数据 |
| 图表/记录摘要 | 真实记录、日期范围、单位、筛选关系 | 无数据不画假线；颜色外提供文字/数值；不能凭训练量声称健康结果 |

沿用样机的移动优先信息层级：适当的深色重点区、浅色内容和受控摄影，不让装饰挤掉记录主操作。内容图、服务照片和图中人物不得直接作为正式教练头像、课程或资质证据；实际素材需有使用权和真实对象关联。旧三套被否定的调色方案不回退为产品选择。

## 两种记录方式

1. 从今天、计划或自由记录进入同一草稿；默认训练后记录，可切换每组完成后记录。模式仅改变布局和确认节奏，不重建会话、动作条目、组键或输入。
2. 动作按稳定条目分组，同一库动作可出现多个条目；支持用户命名的自定义动作。增加、移除、撤销使用明确目标与稳定键。组序号只是显示顺序。
3. 重量型填写实际重量和次数；自重/呼吸型填写实际次数；时长型仅填写实际秒数；每侧数据标明“每侧”，不自动推算左右或合计。各类型的范围和合法组合由已接受合同与服务器共同校验。
4. 空白行保留为草稿，不计为完成；半行明确提示补齐或移除。上次数据只作带来源的参考，用户明确沿用后才作为输入。
5. 日期默认本地适用日，可选过去有效日期；服务端按会话冻结时区校验。日期、请求接收和保存确认时间分开，不展示推测的训练开始/结束或逐组完成时刻。
6. 保存结果区分服务器已保存、待同步和失败；同一请求重试不产生副本。412 时保留草稿，展示本机与服务器同组差异，让用户处理后重试；切账号隔离本地草稿与待同步队列。
7. 保存后的修改仍是原记录。删除须有明确目标、确认及可撤销路径；移除最后一组后不展示空的已完成记录。没有训练播放器、开始/暂停或休息倒计时。

## 三端和状态验收

- 微信小程序、iOS、Android 的导航、输入、文件/分享、通知、登录和生命周期由平台适配层提供；页面不直连数据库或模型。图片中手机号登录仅示意，实际能力和文案等 K01-02/P02 确定。
- 对 320/390/430 逻辑像素、横向空间变化、长中文、200% 文字、屏幕阅读顺序、触摸目标和对比度分别检查；控件不可因固定高度截断。关键触摸区域按项目目标至少 44×44 逻辑像素，平台需要更大时遵循更大值并实测。
- 小程序顶栏胶囊与页面内容不重叠；iOS 与 Android 各自避开安全区、系统返回和软键盘；记录实际设备、系统/微信版本、尺寸、字体缩放和截图。H5 或模拟器不能代替三端真机。
- 支持 Reduce Motion：关闭非必要缩放、位移和自动轮播，仍保留等价的状态、焦点和错误提示；动效不是状态唯一来源。
- 每个页面至少登记加载、正常、空、失败、重复操作；涉及版本/权限的页面另测过期、撤权、切账号和恢复。无法产生某状态时注明原因，不以静态图代替实际交互。
- 画板文案和示例必须在实现时逐项替换为真实状态；三端新截图、内容/素材来源、日期和同一集成版本留到对应任务证据中。正式接入前运行的模型、业务服务、审核和付费效果均不得凭本文件宣称通过。

# D02 · 账号关联与注销状态规格

状态：文字交互草案，尚无对应的正式视觉稿或三端实现。三端提供同一可发现路径：学员“今天”或教练工作台顶部的账户入口 → “账户与安全” → “关联账号”或“注销账号”；微信小程序的入口避开胶囊区域，具体视觉由 U01/U08 适配。三端遵循同一服务端主体与操作结果，不能仅凭客户端缓存判断身份或授权。

## 入口、回跳与页面骨架

- 账户入口必须有可读名称“账户”，不能只依赖头像辨认；登录后进入“账户与安全”，在同屏列出当前身份、关联账号、隐私与共享、注销账号。注销与退出登录分别呈现，且注销入口不藏在外部网页。教练与学员角色均可到达同一账户控制。
- 从记录或其他任务按需登录时，保存可恢复的页面位置和本机草稿，成功后回原任务；取消回到原任务，未同步数据仍标注为草稿。主体不匹配时不展示或自动提交另一主体的草稿，匿名草稿能否迁移及确认方式以 K01-02 接受的合同为准。
- 用户操作预算：进入账户与安全最多两次导航；关联或注销各保留必要的本人验证与一次明确确认，不增加与任务无关的建档或资料填写。实际平台验证步骤由合同与平台能力确定。
- **关联页面骨架**：当前账号 → 当前可用的已核定身份方式 → 验证及双方确认（合同要求时）→ 明确结果和“返回原任务”。未核定方式不展示可点击的虚构入口。冲突显示“无法自动合并账号”，不展示不属于本人的私有资料。
- **注销页面骨架**：当前账号与影响 → 本人验证 → 明确提交 → 处理中/完成/需处理。未确认前有返回；提交后是否允许取消以服务端状态与已核定策略为准。状态无可靠证明时说“暂时无法确认”，不说已完成。
- 会话在注销处理中失效后，只使用 K01-03 实际提供且已验收的安全身份确认和查询路径；该路径尚未确定时不发明公开进度链接或把重新登录视为撤销注销。

## 账号关联

| 状态 | 用户看到什么 / 下一步 | 系统与边界 |
|---|---|---|
| 未关联 | 显示当前已验证身份及可用的关联入口 | 具体登录方式由 K01-02 确定；不预设手机号、微信或 Apple 一定可用 |
| 发起与本人验证 | 说明关联用途，用户主动选择并完成本人验证 | 显示当前主体；保存进入前的草稿与回跳位置；取消返回，不创建关联 |
| 等待对方确认 | 告知需要在哪一端/方式完成确认，允许退出或在有效条件下取消 | 不以客户端声称另一身份已验证；过期时给可重试入口 |
| 成功 | 展示已验证的关联及可返回原任务 | 服务端确认后再刷新身份；原草稿和同步队列仍按原主体隔离 |
| 已归属其他账号 / 冲突 | 明确不能直接关联并给安全恢复路径 | 不自动合并两套账号、训练记录或授权；若无安全路径则保留原账号并说明无法继续 |
| 网络/验证失败 | 保留当前任务，说明可重试或稍后再试 | 未获服务器成功确认就不显示已关联；重试遵守合同的防重复与版本规则 |

## 账号注销

1. **入口与说明**：本人进入注销流程，先展示当前账号、将失效的登录方式、服务/关系及健康数据的处理范围；实际删除、允许保留的法定或审计例外、备份处理和时限以 L01-03 核定策略及服务器返回为准。未核定部分不编造天数或承诺。
2. **本人确认**：明确用户正在请求注销，并完成 K01-03 规定的本人身份校验；用户可在提交前取消。不能预勾选、以普通退出登录代替注销，或把用户草稿静默发送。
3. **提交和重复请求**：展示处理中；重复点击复用同一请求，不产生多单。是否允许撤回已提交申请以服务器状态和实际政策为准，只在确实可撤回时显示操作；失败保留当前页面并说明安全重试方式。
4. **进度与完成**：清楚区分“申请已提交”“处理中”“已完成”和“失败/需处理”，以服务端结果为准；若登录会话先失效，给出合同允许的身份确认与进度查询方式，不能通过不受保护的公开链接泄露账户状态。完成后按服务器结果回收各端会话、清理本机该主体缓存和待同步队列，显示已发生的结果及可继续的下一步。
5. **跨端与恢复**：小程序和两种 App 对同一主体展示一致状态；旧令牌和缓存不能恢复访问。需说明已核定的保留或删除范围；备份恢复后也必须遵守删除/撤权状态，具体执行与证据归 O03。

## 采集同意和共享授权

画板 27 的“一次同意”只是信息呈现方向，不能作为全部健康数据的总授权：按实际字段和用途分别说明并取得明确同意，允许拒绝和撤回；过敏原、伤病等以各自合同和通知版本为准。画板 28 的教练共享授权是另一操作，用户逐范围选择；未获得授权不得读取、推断或发送数据给 AI。服务端确认撤回后立即阻止新的授权读取与后续处理；收到结果或重新校验后，开放页面与缓存变为无权占位。离线设备无法立刻获知远端撤回，不得因此宣称已远程擦除数据；受授权约束的教练健康内容在无法验证当前权限时不重新展示，已送达通知不能承诺撤回。细节见 [跨端状态矩阵](platform-state-matrix.md)。

以上入口、状态、账号绑定和注销的真正页面及截图仍由 U08 等实际任务实现与验证；[跨端状态矩阵](platform-state-matrix.md) 给出键盘、安全区、系统返回及失败恢复的实施条件，目前没有可引用的 U08 最终画面。

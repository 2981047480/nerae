# 视觉与动效的逐项决定

本稿是主代理从意图收敛出的实施目标，不是从风格库随机抽取的皮肤，也不宣称已被目标用户验证。先验收少量代表情境的整体质感，再扩展全量；执行者不能把所有活动套成同一版式。

## B01 专业来自可判断

动机：学员要理解适配与约定，教练要认真判断。决定：内容完整、单位与状态准确、排版有秩序、细节稳定。视觉上以清楚的字级和精确边缘关系建立可信度；服务包价格与内容相邻，审阅能看全案。动效以明确反馈解释状态，不营造假安全感。验收不看“专业”字样出现次数，而看用户能否解释对象、依据与后果。

## B02 活力来自行动节奏

动机：训练有开始、投入、组间恢复与完成，不应像填行政表。决定：探索有真实训练内容吸引力，执行进入专注，完成收束到真实记录。视觉上的力量来自对比、构图与动作内容，色彩只作有限强调；不靠连续闪动。动效与实际动作同拍，一次确认得到短而清楚的回应，不延迟下一步。

## B03 陪伴来自具体回应

动机：人的存在要通过可核对的互动建立。决定：教练身份、具体回复、所引用的训练和改动清楚相连。人物图像有来源；没有合适授权素材时使用正常姓名头像，不把陌生照片包装成真实认证教练。AI 身份单独标明。动效帮助看见新回复与引用关系，不能伪造已读、关注或实时在线。

## B04 成长来自可理解积累

动机：用户需要认出自己的投入，不需要每次突破的压力。决定：记录有明确时间范围、来源、单位和个人比较条件；没有数据不填假图。图形只为解释记录，身体结果不由单次训练推断。动效基于真实变化，不播放假增长或必胜庆祝。验收核对汇总与明细，不凭一张曲线接受。

## B05 品牌来自持续表达

动机：需要同一产品身份，又要适应多种注意力状态。决定：共有色彩角色、中文排版、轮廓、图像语气、图标和动画节奏；探索、训练和审阅有不同密度。品牌名只作名称，不臆造神话或疗愈故事。高级感来自组合和细节，不靠金色、玻璃、霓虹、极小灰字或巨大空白。验收跨全部代表情境检查一致与区别。

## V01 排版与字形

意图：短暂扫视可辨主次，数量与单位准确，长服务说明可以认真阅读。

决定：以中文系统无衬线为正文基础，优先 PingFang SC / Noto Sans SC，英文与数字使用兼容的现代无衬线；普通数据用 tabular-nums，不把全产品排成等宽代码终端。字重控制在 400 / 500 / 600，避免所有标题与按钮一起加粗。

规格目标：正文 16px / 1.65；辅助 14px / 1.5；少量时间来源 12–13px，但不能承载重要限制或按钮。页面标题 26–30px；训练主题可 32–36px；核心记录数值 40–48px，真实休息计时可 56px。大小依据任务，不让所有页都出现一个大数字。

验收：390 / 320 宽的中文换行、数量单位、200% 文本、字体加载失败。长标题不能压缩成小灰字，关键内容不靠省略号；不能用海报标题抢训练操作。

## V02 空间与布局

意图：眼睛理解的顺序与手的动作顺序相近，移动端从身体与注意力出发。

决定：手机以完整 App 空间呈现，拒绝网页中再套手机外壳。主要内容边距约 20px，窄屏 16px；空间基于 4px 节奏。相同关系保持固定间距，不用随机大空白制造高级。

探索可用图像和内容序列；今天有一个清楚主任务与恰当次级内容；训练聚焦当前组；审阅有内容和差异；会话留给消息。桌面可在同一画布展开上下文，最大内容约 1240px；不能把手机无限拉宽或让所有页面变成左右两张白卡。

验收：320 / 390 / 430 / 768 / 1440，短内容不空洞，长内容不被固定操作遮挡；虚拟键盘、safe-area、弹层与底部导航均可操作。

## V03 分组与容器

意图：容器解释信息关系，不是用来给每段文字加背景。

决定：主训练内容、公开计划封面、需要集中判断的服务 / 审阅对象可以有独立面；普通记录、动作、待办优先用编排与分隔组织。禁止卡片套卡片、每行同形胶囊、无语义彩色小方块图标。

布局中保留“主面 / 平面内容 / 关联说明”的区别。按钮、输入、弹层轮廓稳定；默认主要面圆角 16px、控件 8px，头像为圆形，封面随内容裁切。不要把所有对象都做成巨型圆角卡片。

验收：去掉某个容器是否仍能理解关系；同一组是否被割碎；不靠阴影叠加区分全部层级。

## V04 色彩与明暗

意图：在安静背景里保留训练活力，重要状态与品牌表达相互区分。

当前实施目标：矿物浅底、深蓝灰主色、少量暖陶色强调，避免回到旧版松绿或纯黑白记录表。选择理由是给图像与真实内容留空间，在需要执行时有明确力量；它是本轮可检验的决定，不能写成用户已偏好的颜色。

| 角色 | 候选值 | 用途 |
|---|---|---|
| canvas | #F3F2EE | 安静的主背景，不做整屏米黄装饰 |
| surface | #FFFFFF | 需要独立判断的内容面 |
| ink | #192F39 | 正文、主按钮与品牌深色 |
| muted | #5E6B70 | 仍可读的次级信息 |
| line | #D9DDDA | 结构分隔与输入边界 |
| accent | #C97857 | 少量动作强调和当前数据，不能铺满所有卡片 |
| onAccent | #0D1B21 | 暖陶色面上的文字，常规 ink 与 accent 的对比不足，不能替代此值 |
| focus canvas | #162A33 | 训练执行专注空间 |
| focus surface | #223C46 | 深色执行中的输入 / 控件面 |
| positive | #276F53 | 真实成功与有效状态，配文字 |
| warning | #805C22 | 需要关注的事实，配原因与恢复 |
| error | #A23F3D | 错误或危险，不能用于漏练羞耻表达 |

正常阅读与主要操作优先 ink / 白色组合；陶色上的文字使用 onAccent，不用白字或普通 ink。accent 不作为浅底小字，浅底关键线条用 ink；在专注深底可用 accent 标记当前数据。照片可用局部遮罩保障文字可读，这不是装饰渐变；其余不做背景渐变、光晕和玻璃。

验收：逐对测普通文本 4.5:1，主要图形 / 边界 3:1；失败与成功另有文字；明暗切换不会改变同一动作的意义。

## V05 形状与材质

意图：可操作、稳定、可接近，避免表面特效替代质感。

决定：以哑光实体面、精确边缘、内容裁切和有限对比形成深度；只在需要悬浮关系的弹层 / 浮层使用轻微阴影。主界面不用大面积毛玻璃、金属光泽或亮面渐变。点击反馈短促，输入与选择有清楚边界。目标触达 ≥48px，最低不可低于 44px；大小不等于可见图标尺寸。

验收：遮掉颜色仍能识别可点与不可点；休息状态不是伪按钮；按下、焦点、禁用和错误均有可辨变化。

## V06 人像与训练图像

意图：探索有内容吸引力，服务者可辨认，普通训练者能代入。图像不能承担不存在的权威或安全证明。

决定：使用有出处的高质量训练 / 器械摄影，图像语气自然、克制，人物不以体型结果作卖点。主封面采用足够分辨率的完整摄影裁切，不能用手绘 SVG 哑铃、文字方框或 emoji 假装高级素材。动作教学素材需可靠来源，普通封面不冒充动作指导。

素材来源、作者 / 许可和用途记录在开发报告，实际文件本地保存；不依赖不稳定随机图片 API。若某项素材无法合法取得，先报告缺项并用同主题真实器械摄影调整构图；不把空色块或损坏图片提交为完成。

验收：实际看所有封面、裁切、加载失败与替代文本；人像不得与虚构的真实认证、成绩和背书绑定；图片不是相同素材机械重复。

## V07 图标与细节

意图：快速识别熟悉操作，细节保持统一。

决定：统一采用成熟线性图标库（优先 lucide），同一动作使用同一图形与笔画。重要动作配文字，图标按钮有可访问名称。导航图标与正文的光学尺寸稳定，数量和单位对齐。品牌用克制字标，不把首字母塞进彩色方块当通用 SaaS logo。

验收：可见按钮、焦点和 aria 名称；不混 emoji、实心与线性多套风格；不出现“看起来能点”的无动作装饰。

## V08 动效、触感与声音

意图：说明因果、对象连续和状态，给动作适当分量，避免等待与炫技。

决定：使用少量统一的速度和缓动；状态变化可以无动画完成同一结果。网页不假装已经实现震动、锁屏、后台通知等系统能力。默认不主动播放声音，不循环呼吸主按钮。

下面是必须实现并验收的动效合同。执行者可用 CSS / Web Animations / Vue transition，但同一动作不能混入不同节奏；需要库时先保持局部依赖，不能新建全局动画框架。

| ID | 触发与对象 | 行为与时长 | 用户能感知的结果 | 减少动态效果 |
|---|---|---|---|---|
| M01 | 稳定空间内切换 | opacity + 约8px位移，180–220ms，进入轻快、退出更短 | 知道换到哪个任务 | 立即呈现，保留焦点与标题 |
| M02 | 选中计划 → 详情 | 所选封面 / 标题接续或局部交叉淡入，240–300ms；不整页飞行 | 当前内容仍是同一份计划 | 直接显示同图同标题 |
| M03 | 今天 → 专注训练 | 主任务区域接续为执行空间，220–280ms；次要内容退后 | 进入当前会话，注意力收拢 | 立即切换并说明当前动作 |
| M04 | 确认完成一组 | 当前组转为已记录，勾选短促反馈120–160ms，进度跟随实际数，下一组平稳接续180ms | 哪一组被记录、接下来哪组 | 文字状态和数值立即更新 |
| M05 | 休息计时 | 数字按真实时间变化，无持续缩放 / 闪动；结束一次局部反馈 | 剩余时间与下一步 | 同样可读的数值与文字 |
| M06 | 弹层 / 确认 | 底部内容位移约20px + opacity，180–220ms；背景遮罩随之出现 | 操作上下文未丢失 | 立即出现，焦点与关闭行为相同 |
| M07 | 草稿字段变化 → 差异 | 仅相关行以短暂底色强调后回落，约300ms | 改了哪里，不隐藏完整方案 | 变化说明保持，不依赖闪色 |
| M08 | 消息发送 / 失败 | 新消息自然占位与淡入120–180ms，状态跟实际预览事件；失败保持原文 | 发出 / 未发出、可重试 | 立即添加，同样保留状态 |
| M09 | 查看记录范围 | 现有图形更新160–220ms，范围和单位同时更新，无假增长 | 看到的是哪个范围 | 直接更新数据与文本 |
| M10 | 主操作按压 | scale约0.985 或明暗变化，70–100ms，松开恢复；不中断点击 | 操作已被接收 | 明暗反馈，可不缩放 |
| M11 | 教练切换学员上下文 | 保持队列位置，内容短交叉淡入160–200ms；明确选中对象 | 正在处理谁 | 直接更新选中与标题 |
| M12 | 恢复 / 同步状态改变 | 只更新状态和相关内容，约160ms；错误无抖动与强制弹屏 | 内容是否保留、下一步是什么 | 同样文字与恢复按钮 |

默认缓动为 ease-out 风格的快速进入、缓慢收束，可使用 cubic-bezier(.2,.8,.2,1)。避免所有元素依次 stagger 入场，不用长开场阻挡训练。动画中第二次合法操作可继续；过渡不能留下失效点击层。离开页面及时取消计时 / 动画句柄，返回按真实状态恢复。

## 首个视觉检查必须覆盖的四种节奏

1. 学员今天：有明确训练任务与恰当内容吸引力，不是空白欢迎页。
2. 探索计划：可比较且有质感的内容序列，不是电商促销墙。
3. 训练执行：专注、可单手记录，有短促准确反馈，不像普通表单。
4. 教练审阅：完整内容、依据与差异可读，不像工单后台或三条空摘要。

主代理在相同宽度看实际渲染，并检查进入、返回和完成动画。四种节奏成立后才扩展其他情境；不得凭静态源码或模型自评宣布视觉通过。

### 四种代表构图的执行约束

- 今天：手机首屏以一块有真实摄影与训练内容的主面建立重心，主题、当前进度和继续操作相互靠近；不要回到“问候标题 + 日历 + 两张白卡 + 手画哑铃”的旧构图。次级内容有内容节奏，不等高排成后台磁贴。
- 探索：摄影裁切、标题和可比较事实共同形成内容序列。允许一大一小的节奏与平面内容区；禁止全屏同形胶囊、促销角标和重复的宣传短句。
- 执行：深色画布与当前组形成专注空间。重量 / 次数是可直接操作的训练记录工具，单位和上次参考清楚；主动作与实际完成反馈相连。不是在普通白表单上换黑色背景。
- 审阅：完整方案有稳定行结构与可编辑内容，变更有明确对照；桌面可同看方案和依据，手机按需切换但不能丢内容。对象、当前版本和发布动作形成清楚秩序，不出现假 KPI 或空摘要凑版。

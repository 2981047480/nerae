# 从设计意图到体验决定

本轮决定由主代理承担产品、交互与视觉判断。它们是供实现与验收的明确设计决定，不冒充真实用户研究。业务范围和日期、确认、撤权规则继续引用 PRD / APP_FLOW，不在此重建一套业务规格。编号用于追踪，不能渲染到产品。

## G01–G07：先处理产品基因

### G01 人群与熟练度

动机：18–28 岁说明首期服务对象，不能推出统一的竞技审美或同一熟练度。首次使用的人需要选择依据，已有训练习惯的人需要快捷接续。

产品决定：新用户可以直接浏览训练内容；有正在进行训练时优先接续。训练经验、器械、可投入时间采用少量可撤销偏好，完整身体资料不成为浏览入口。

交互决定：偏好选择即时更新结果并保留上次值；不在首次打开时弹多页问卷。空结果只提示放宽当前条件。用户随时能看全部内容。

UI 决定：探索呈现可比较的内容与适配事实；训练保留高对比、清楚单位和可触达操作。首屏没有与当前动作无关的年轻化装饰。

验收：匿名可到计划详情；选择条件后能撤销；有会话时两次以内进入训练；新用户不面对空白仪表盘。关联 N01、L02、C01/C02、V01/V02。

### G02 免费使用的独立价值

动机：用户即使不选择教练，也应获得完整的开始、执行、积累与整理路径。

产品决定：免费计划、我的计划和训练记录独立闭环。教练出现在用户需要指导的探索与反馈语境中，不成为每次训练的必经关卡。

交互决定：使用计划时 App 自动完成必要副本和安排衔接；收藏是可选的另一意图。已有安排时默认继续，替换须说明后果。发布复用已有内容，不从空表开始。

UI 决定：免费内容采用与教练交付同等认真的内容编排；不会把免费用户的今天做成“解锁更多”的广告位。

验收：从探索到完成训练无教练选择阻断；记录能回来查看；我的计划能编辑和进入发布审阅。关联 L01/L04、C01/C04、T01。

### G03 自主选择教练与自主经营

动机：用户需要判断是否匹配，教练需要清楚表达服务差异；平台并不替双方作选择。

产品决定：比较依据为目标、经验、服务内容、响应约定、可投入时间和价格语境。详情展示结构化交付样例及来源；样本不足时不制造评分精度。

交互决定：筛选保留，详情返回原位置。发起咨询带入选择的服务包和已知偏好，备注可选。教练可以编辑自己的服务说明与价格，保存不等于公开或成交。

UI 决定：人物有清楚身份与真实信息层次；照片不是权威证明。价格与服务内容相邻，评价和样例附时间与上下文。没有竞价排名、商城购物车或伪支付成功。

验收：可以比较两位教练、看服务差异、带着当前服务包进入咨询；教练保存服务内容后回读一致。关联 N01、L03、C05、V06、T01。

### G04 记录与人的反馈相连

动机：陪伴通过具体回应发生，用户不应在消息和训练记录间反复搬运信息。

产品决定：点评引用具体训练和动作；调整与原计划关联。学员收到的是可理解的变化及教练的具体建议，而非孤立的“新计划”通知。

交互决定：从记录能打开关联点评；从消息引用能返回同一记录；采用调整前先核对影响。返回时保存阅读位置和编辑中的回复。

UI 决定：引用是一段紧凑的上下文摘要，可展开真实内容；人的回复保持自己的署名与时间。未查看、未回复、已交付、尚未采用分别表达。

验收：完成训练后能看到对应反馈入口；引用不跳错训练；旧计划仍可查，交付不自动替换。关联 N03、C04/C06、L05/L09。

### G05 AI 减少整理负担

动机：用户需要一个具体任务的帮助，不能为了使用 AI 先组织平台已经知道的材料。

产品决定：在计划解读、已有模板调整、发布整理和教练草稿处提供上下文内的 AI 入口。保留原有手动路径，不用聊天框替代整个产品。

交互决定：自动带入对象和当前版本；先展示可审阅内容及改动，重要应用由用户确认。缺项只问缺项；安全阻断、技术失败、额度状态分开，安全阻断不换一种生成方式绕过。

UI 决定：AI 是内容来源与状态标识，不是全屏品牌装饰。输出解释用户相关事实，不能出现“为了降低认知负担”“本模块体现”等设计说明。

验收：AI 失败时仍可记录训练；未确认不改安排；缺项与失败恢复不同；教练计划不能由学员 AI 直接改写。关联 L06/L07、C06/C07、T03/T04。

### G06 服务边界与信任

动机：产品不处理收款，不能用漂亮成功反馈制造交易或授权事实。

产品决定：咨询、服务说明、双方确认与授权是可辨步骤。未核定渠道保持不可用，但保留咨询与站内恢复路径。示例交互不产生真实外部联系。

交互决定：重要确认前展示对象、范围与影响；取消不丢已填内容。年龄确认只在开始服务时出现。健康授权独立于服务确认。

UI 决定：确认以清楚的摘要呈现，不以长法律墙覆盖任务。无“立即支付”“平台保障成交”等错误承诺。

验收：未确认关系不显示服务激活；拒绝健康授权不阻断普通安排沟通；无真实支付入口。关联 L03/L06、C05/C06、T04。

### G07 时间、版本与连续性

动机：用户要相信记录与约定不会因 App 的新安排被改写。

产品决定：今天显示当前安排；历史显示当时快照；新版交付和采用分别发生。暂停、休息、漏练、周期结束各有合理返回路径。

交互决定：同一组只记录一次，失败使用同一事件重试；重新进入恢复首个未完成组和未提交输入。恢复只影响当前与未来，不制造过去义务。

UI 决定：日期、当前版本和同步状态在需要判断时明确；默认界面不呈现内部 hash、CAS 或数据库 ID。

验收：刷新、退出、失败和重复进入不丢输入或增组；完成后回今天不变成休息；采用新版本不改旧记录。关联 L04/L09、C02/C03/C08、T02。

## N01–N03：将心理需要落实为操作

### N01 自主

用户选择目标、内容和人；系统准备可理解的默认项。默认项始终可见、可改，普通动作可返回，重要替换可取消。禁止用预选健康同意、隐藏退出或强制选择教练制造顺畅。关联 G01/G03/G06；检查取消与返回路径，而非仅检查确认成功。

### N02 胜任

每次使用应更容易理解下一步。训练以明确动作、单位、上次参考与当前事实帮助行动；练后将个人记录放回时间范围内理解。空记录不显示假成绩，不用“超越 90% 用户”代替本人积累。关联 C03/C04、L05、V01；检查单位、比较依据与信息不足状态。

### N03 关系

指导的价值通过具体训练被引用、具体变化被解释、具体问题被回应来表达。自助用户仍有完整价值，不被表达成“无人照顾”。AI 与教练身份不混淆，未回应不自动标记关怀。关联 G04、C06/C07、B03；检查消息引用、署名、时间和读取状态。

## L01–L09：九层逐项收敛

### L01 价值与身份

决定：Nerae 的共同身份是认真但可接近的训练服务。学员是能作决定和积累经验的人；教练是有判断力与个人服务身份的人。探索、训练与指导属于同一条成长过程。

体现在产品：免费训练与真人指导同等成立；体现在交互：开始与接续优先，深度编辑按需进入；体现在视觉：有训练内容与人物存在，也有清楚秩序，不能成为通用 SaaS 工作台或促销商城。

动效作用：将选中的内容接续为详情与执行，强化对象连续性。检查：遮住品牌名仍能从内容、节奏与行动判断是训练服务；不是任意改名字就成立。关联全部 G 项。

### L02 使用情境

决定：按注意力状态区分探索、执行、判断、交流与回归。共用语义和操作习惯，密度与节奏可变。

UI：探索允许丰富内容和完整图片；执行减少竞争信息、数量和动作更清楚；审阅以完整方案和变更对比为核心；会话让文本与引用自然流动。关键操作在手机可触达区域，键盘不遮盖确认。

交互：训练过程中不弹营销；专业审阅不因常规操作速度指标被压缩；返回保持内容与位置。动效：探索→执行渐收信息，记录反馈短促，审阅切换克制。检查：C01–C08 均有适当密度，不能只是一个列表换标题。

### L03 心理与信任

决定：用可核对的依据减少顾虑。内容适配、服务边界、数据保存、交付对象四种顾虑分别处理。

UI：来源、适配条件、响应约定和具体保存状态靠近相应判断；关键信息不藏在多级帮助中。交互：撤权与拒绝有正常出口；未确认内容不伪装为事实。动效：成功反馈跟随真实本地预览状态，失败保持原内容。

检查：学员能解释为什么选该内容和该服务；教练发布前能确认对象、内容和影响。没有服务证据时不画“高可信”评分。

### L04 体验结构

决定：活动衔接优先于后台模块边界。发现内容、训练执行、记录理解和真人指导可顺畅往返。

产品导航：学员的稳定空间承接今天、探索、记录和联系；教练承接待处理、学员和服务内容。具体层级见开发文稿，不能把数据库对象数量变成导航数量。

交互：打开深链后保留来处，登录回跳保留选择；开始计划自动完成必要衔接。动效：同一对象的进入、退出和返回有方向感，跨业务活动不滥用共享元素。

检查：执行 F01–F07 不需自己复制 ID、选一遍相同学员或重复填写模板信息。

### L05 信息层级

决定：先给当前问题的答案，再提供作判断的证据，再放其他选择与历史。并非每屏只能有一个按钮，而是主要路径容易辨认。

UI：动作和数量清楚，辅助说明与来源退后但保持可读。服务包的价格与交付内容相邻；审阅时完整内容与改动都能看，不让“一行摘要”替代方案。

交互：次级内容按需展开，关键限制在决定前出现。动效：展开直接揭示关联内容，不自动滚动打断正在阅读的人。

检查：短暂扫视能说出当前位置、主要任务和下一步；长内容、空、失败仍保持层级，不靠删必要信息换简洁。

### L06 交互责任

决定：用户作判断，App 做重复执行，AI 作有依据的草稿。每条路径必须列出决定、执行、推断、确认与结果。

产品：自动预填资料、接续对象、保存输入与恢复；重要后果清楚确认。UI：输入标签常显、单位稳定、错误靠近字段；禁用须给可行动原因。

动效：点击有即时触感，异步动作有明确状态，结果不先于实际状态。检查：动作预算、重复点击、取消、返回、刷新和失败恢复。认知/执行负担分数为启发式评审，不能伪称实测。

### L07 内容表达

决定：产品只说用户现在需要理解的事实与动作。内部推理、设计理由、组件结构、验收口径只留在文稿与报告。

UI 文案：例如“接着第 4 组”“这条消息尚未发出”“查看 3 处调整”可以出现；“通过层次减少认知负担”“本页采用低饱和色体现专业”禁止出现。AI 的来源、估算和待确认状态属于用户需要的信息，可保留。

交互：错误说明发生什么、内容是否保留、能怎样恢复；鼓励对应具体事实。动效：不用长动画替代结果说明。

检查：按用户相关性审查每一段可见文字，不能只查几个禁词。首屏不放产品理念、开发技术或演示使用教程长段落。

### L08 视觉语法

决定：高级感由一致比例、内容节奏、精确中文排版、合适素材、节制对比和细节完整共同建立。它不是全黑、玻璃、巨大数字或空白的同义词。

UI：建立单一视觉词汇；探索的内容图像、训练的专注工具感、教练的判断密度各有合适表达。布局从内容与使用环境推导，容器只标记真实关系。具体规格见视觉文稿，执行者不得自由混入第三套组件皮肤。

动效：使用同一组速度与缓动，允许任务反馈不同长度。检查：同视口比较整体构图、字重、间距、素材、按钮和状态；技术通过不代替主代理视觉判断。

### L09 时间与感官

决定：界面要解释动作的因果，并在重复使用中保持连续。动画服务进入、确认、变化、恢复与结束。

UI：当前、下一步、已完成与待同步可辨；没有记录时不播放假增长。交互：真实计时、暂停恢复与重复事件去重；会话历史不被无条件滚底打断。

动效：路线、共享内容、组记录、底部弹层、差异更新和消息各有约束；减少动态效果时结果与文字等价。声音和震动默认不主动开启，不假装网页具备未实现的系统能力。

检查：键盘、低宽度、重复切换、动画中点击和 Reduce Motion；任何动画不得挡住下一次合法操作或造成虚假成功。

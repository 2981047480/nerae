# 取舍与证据边界

## T01 免费价值与真人服务转化

动机：两条价值链必须各自成立。决定：今天以当前训练为主；探索可选择内容或教练；成长反馈允许在具体问题语境中寻找帮助。训练中不插服务促销。UI 的主要行动优先用户当前意图，教练入口稳定可找，不用焦虑文案制造转化。验收：完整自助路径不经过教练选择；咨询仍可从发现直接到达。关联 G02/G03、C01/C05。

## T02 内容探索与稳定训练

动机：新鲜内容与持续执行有不同注意力需求。决定：稳定导航和返回习惯，主内容权重随当前状态变化，不能每天重新搬动入口。UI 今天的正在进行训练可接续，发现保留筛选；详情返回原位置。验收：换页、登录回跳、重开后仍能解释自己在哪里。关联 G07、L04、C02/C08。

## T03 教练效率与审阅质量

动机：快来自少检索与少填表，不能来自略过证据。决定：自动整理和带入，草稿恢复；审阅同时允许看完整内容和具体改动，确认前明确学员与影响。常规操作速度目标不成为专业判断倒计时。验收：从队列到原草稿不超过两次导航，审阅没有自动勾选“全部安全”。关联 G05、C07。

## T04 少输入与保留掌控

动机：预填应减少劳动，而非悄悄替用户作重要决定。决定：来源可见、原值可改；普通保存不加确认墙；替换安排、健康授权、发布和采用说明后果并可取消。验收：取消后输入保留，旧安排与授权不变化；系统不能借默认值制造完成事实。关联 N01、L06。

## T05 激励与压力

动机：让用户看到可理解积累，并保留休息与回归。决定：认可真实投入；不以身体比较、清零威胁、公开排名或虚假健康结果激励。UI 允许“今天休息”“重新安排”成为正常状态。动效认可一次具体完成，不全屏连续庆祝。验收：漏练与暂停文案无评判；完成不承诺结果。关联 N02/N03、C04/C08。

## T06 简洁与吸引力

动机：空白和少内容并不自动高级，丰富也不必然杂乱。决定：以准确构图、内容节奏、图像、空间和状态细节形成吸引力；重要事实不为留白被删。探索允许完整内容，训练强调专注，审阅容纳证据。验收：同视口分别检查每种任务；不能仅以组件一致为由把全部做成相同卡片。关联 L02/L08、V01–V08。

## H01–H05 假设如何影响实现

| ID / 假设 | 当前采用的可撤销设计 | 后续需要的证据 | 不能宣称 |
|---|---|---|---|
| H01 适配摘要帮助首次选择 | 先给可比较条件，仍可看全部内容与直接搜索 | 观察真实选计划的决策顺序和犹豫点 | 年轻用户普遍喜欢这种外观 |
| H02 连续性影响重复使用 | 优先恢复训练与输入；发现入口稳定 | 多次训练、中断返回的真实使用与流失原因 | 已提高留存 |
| H03 具体交付帮助选择教练 | 服务与样例相邻，来源、时间、响应语境可读 | 真实咨询选择过程与误解点 | 样例证明教练服务效果 |
| H04 尊重节奏有助持续关系 | 允许休息、暂停和恢复，反馈具体投入 | 自助与接受指导人群的不同约束偏好 | 已验证动力或健康改善 |
| H05 同品牌可有不同任务节奏 | 共享语义与控件，探索 / 执行 / 审阅不同密度 | 切换时的辨认和任务表现 | 统一配色即可保证一致 |

这些假设形成当前可检验的设计，并非暂停实现的理由。重要之处是保留替代路径、记录依据，之后可用证据修订。

## Q01 先看近期真实行为

当前没有招募或访谈结果。后续研究以“上一次如何开始 / 犹豫 / 切工具 / 返回”为问题，不用喜好问卷冒充行为证据。本轮只作主代理任务走查，报告明确身份。实现需要可从零开始、返回和恢复，便于之后实际研究。

## Q02 检查用户理解的结构

设计检查围绕计划、安排、记录、指导和关系的后果，不要求用户学习内部名词。实际操作应能回答在何处、做什么、将发生什么。检查登录回跳、深链和连续切换，不只检查导航按钮能否点击。

## Q03 吸引力与使用质量分别判断

高级感、美感、交互与动效分别验收。视觉评审看完整同视口截图和实际过渡；功能检查不能替代视觉判断。主代理的审美接受不写成目标人群普遍喜欢。设计推理只在文稿，产品可见内容逐段作用户相关性审查。

## Q04 覆盖重复使用与失败

每个主路径检查首次、再次、中断、恢复、正常、空、失败、边界和重复。动画中再次操作、减少动态效果、窄屏、长中文、键盘与保存失败必须有具体证据。等待一个实际活跃会话，不能仅凭锁文件推断执行中，也不能因观察超时重新派一份任务。

## 本轮接受的含义

接受的是有源代码、有渲染证据、有可运行交互与动画的 UI 交付，不是 Go 服务、真实微信身份、健康数据授权安全、真实 AI 调用、专业安全审核或生产发布。明确的预览数据可用于 UI 状态与交互检查，不能被报告为真实学员、真实成交和实际健康结果。正式业务任务按自己的合同与接受证据推进。

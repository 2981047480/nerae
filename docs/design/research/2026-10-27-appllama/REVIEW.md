# Nerae · Appllama UI 对照研究

2026-10-27 · 状态：研究完成，改进建议待视觉验证。用户仍不满意第三轮 UI；历史 Lead 接受不代表用户认可美感。

## 本轮范围

- 目标：从实际界面定位问题，研究可用于 Nerae 的真实应用模式。
- 角色：主代理顺序承担产品、交互与视觉评审；未委派子代理。
- 基线：主工作区 main / e4610a7；design/prototype 与此前 c33b581 的源文件、构建无差异。
- 输入：CURRENT_STATE、RETRO、PRD 的角色/训练/教练交付章节、APP_FLOW F01–F07、UI_SPEC、round-03 视觉规范，以及浏览器中实际打开的五页。
- 排除：旧轮次 UI、历史市场资料、后台业务实现、OpenDesign 生成。
- 输出：本记录、参考截图/出处清单、当前界面截图。业务代码与现有样机未修改；建议尚未成为下一轮设计规格。

## 判断

当前样机已有可靠的交互结构，但视觉重心仍偏封面展示与文档阅读。今天的大图挤压具体训练内容；动作行信息密集；教练端把计数、分类和版本反复呈现，用户需要在很长的页面中找到当前判断。训练页的单组输入、清楚单位与大按钮值得保留。

“克制专业”可以通过清晰字重、准确的数据对齐和少量强调实现。目前的浅暖底、蓝灰、陶色及泛用摄影形成较柔和的生活方式气质，训练工具和人的服务特征还不够鲜明。这是本次视觉判断，不是用户测试结论；也不能从参考应用的营收推导设计有效。

## 参考如何使用

两组跨应用检索分别覆盖 workout 关键词、平静且主任务明确的首页语义，各按游标查看三页；再看 Strong 开始/执行、Hevy 编辑/Trainer、LADDER 概览、Boostcamp 计划库、MyFitnessPal 日记的相关完整截图序列。共保存并以联系表逐张观察 **91 张不同截图**，涉及 45 个应用；这里只深入上述相关流程，未全面审核 45 个应用。

本次 Appllama 用量从 48 到 64，共 16 credits，余额 1436。无个人收藏板。截图带有 Appllama 出处水印，仅作研究，不作为产品素材。

## 逐页改法与可检查目标

| 页面 | 当前观察 | 建议构图与验证点 |
|---|---|---|
| 今天 | 手机封面约 420px 高，训练主题/进度压在摄影上；下一动作和反馈向下挤 | 紧凑日期/周状态 → 今日任务与进度 → 继续训练 → 动作预览；摄影改为较矮的辅助面。首屏同时看到任务、继续按钮和至少一条具体动作。只在确有教练反馈时出现相关摘要 |
| 训练 | 单组输入清楚；当前输入与历史记录分居上下；重量/次数单位多处重复 | 保留单组模式；参考值与实际输入分开；已完成组以紧凑行就近呈现。完成/休息/下一组在同一操作区域接续；不增加一次确认 |
| 发现 | 首条封面、介绍和两个“完整内容/完整计划”入口占去多数首屏 | 一条精选 + 紧凑列表；每条固定展示目标/频次/时长等少量可比事实，保留一个明确详情入口。长介绍放详情，返回保留位置 |
| 教练待办 | 五个分类计数与五段列表反复表达“各一项”；人物/事项上下文分散 | 一个有原因和顺序的队列，默认接续草稿或待回复；分类作为按需筛选。条目呈现学员、事实、下一动作；标记处理不是回复或发布的额外必经步骤 |
| 计划审阅 | 对象/版本、交付状态、训练日、查看模式、训练日标题和改动摘要层层出现 | 顶部保留学员与交付状态；完整方案内就地标改动，依据靠近相应动作；版本细节按需展开。完整方案可读，草稿/已交付/学员现用仍可辨，发布继续明确确认 |

用户仍决定练什么、选择谁、是否采纳与发布；App 接续训练、带入资料并保存位置；AI 只给有来源的草稿；授权与重要替换继续显式确认。以上不改变 PRD 或合同规则。

## 建议的下一轮验证

先验证今天、训练、发现三个代表页，达到用户认可的层级与气质后再扩展其余页面；这只是视觉采样，完整产品范围仍覆盖原有各界面族。方向为明亮、直接、有运动感的专业工具；字号层级、数据对齐与主操作优先于配色定案。以单一强调色测试，暂不重新锁定色值或生成全套 token。

每页比较首屏主任务是否三秒可辨、进入训练的点击数是否保持 ≤2、是否重复展示相同事实、同屏主动作是否清楚。实现阶段再验证长中文、320/390 宽度、放大文字、键盘、空/失败/恢复/重复、普通与减少动态效果。参考静帧不能证明导航语义、动效质量或 60fps；本轮也没有原生模拟器/真机验收。

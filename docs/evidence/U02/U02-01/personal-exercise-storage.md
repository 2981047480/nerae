# 本人动作库存储候选

2026-11-16，状态：服务端基础候选，未开放接口、未部署、未接入 App。

本人动作使用稳定的 16 字节随机身份；不同用户的数据按主体隔离。名称与可选部位、器械标签加密保存；同一用户的重名通过用户域 HMAC 检查，大小写与 Unicode 规范等价的名称不能重复。修改采用版本比较，允许重试紧邻的相同写入；每次新版本与其历史名称和标签快照在同一事务中写入。个人动作的密钥使用独立用途派生与独立 epoch；库内已有数据时禁止把空 epoch 当成新库初始化。搜索在授权事务内分批解密、按名称匹配：每次最多扫描 200 项，空结果仍可能带有下一页游标。

已验证：Go 领域和存储测试、关联包竞态测试；腾讯云上无网络的专用 MySQL 容器使用合成数据验证加密、不同账户隔离、同名并发、改名保留编号、版本冲突、重复提交、密钥误重置、历史快照写入失败回滚，以及 201 项跨页搜索。独立 MySQL/Redis 业务装配中，两把合成设备密钥经批准后，通过真实账号会话验证未成年人状态阻断、同主体读写、搜索和改名前快照读取；这不是实际手机验收。正式迁移工具在隔离库使用库级受限账号依次执行 20 项、升级到 21 项和 22 项并重复 22 项，验证旧版当前快照原样回填，均通过；该库无真实数据。

2026-11-16 接缝候选：服务端内部训练快照可保存本人动作的稳定编号、版本及当时名称；加入训练时，存储层在同一事务核对账号归属及该版本的真实名称，不信任调用者提供的名称。原自定义名称快照保持格式 2；包含本人动作时写格式 3，使旧服务不能误读或覆盖。隔离 MySQL 合成测试验证跨账号、伪造名称、未来版本被拒绝，以及改名前名称写入训练后可取回；证据为服务器 `/tmp/nerae-personal-exercise-evidence-ceok0c6v/personal.log`。这还不是客户端可调用功能：现有 HTTP 合同、响应投影和客户端仍不接受该新身份。

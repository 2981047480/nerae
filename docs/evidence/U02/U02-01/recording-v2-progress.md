# 训练记录格式 2 集成候选

2026-11-16，状态：开发及隔离验证中，未接受、未部署、未签装。

本轮在用户认可的白底灰阶方向上，打通自由训练自定义力量动作的候选链路：两种模式共用本机草稿；整场完成时保留的组包括空组和缺项组；完成详情显示逐组内容及服务端按动作计算、带 kg 单位的可计算累计。已同步的组可移除并恢复；当前本机草稿存在时不会被云端恢复覆盖。

本机受保护版本槽保存草稿与一个不可变待发请求。客户端先查原请求的短期回执，再核对服务端版本；有匹配回执和新鲜快照后才原子更新本机元数据，保留期间新增的输入。没有回执时只对相同请求尝试重发，版本不一致留待核对。新请求键使用平台安全随机数。登录后、App 回到前台、网络恢复和关闭编辑器后会扫描本账号的本机草稿；正在编辑的草稿跳过，以免并发写入。进程被系统终止后不保证后台运行，重新打开会再尝试。冲突保留本机内容；当两端动作和组的结构一致且没有待核对请求时，可逐项比较日期、记录方式及组值并明确选择。确认前重新读取云端并检查本机内容，已变化则重新核对；内容完全一致时自动继续同步。新草稿仅在服务端快照核对一致后升级为 schema 4，记录可信的本机变更基线；旧 schema 3 内容不一致时继续要求核对。schema 4 本机没有未同步修改、原有动作和组均可对应且服务端版本经二次核对时，可自动拉回另一端改动及新增的动作／组。iOS 和 Android 原生存储拒绝旧式写入覆盖 schema 4；升级需要同时更新原生插件，不能只热更新 JS。本机保存失败时不继续同步，可重试。本机改动已有组、另一设备只新增动作或组时，现在可逐项选择差异并保留远端新增内容；本机新增或移除、远端删除或移动、本机有改动且完成状态不一致、未结算请求及整条删除的冲突仍未支持合并。

自由训练的两种记录方式已增加批量填写候选：从已填写组的半屏进入，选择本动作段的现有组、重量或次数，也可在同一操作中新增组；未选择的组和字段保持原值。输入为空不能作为批量值，失效的组选择不能提交；批量变更经一次受保护本机写入，保存失败可重试。客户端合成测试覆盖只改第 1／3 组、只改重量、新增组、离线完成与响应丢失重试；组件内部渲染核查了 390×844、320×568 及 20 组滚动和长名称，截图为合成数据的 [WebKit 组件证据](batch-input-webkit-qa.png)，并非真机或最终视觉验收。计划目标和批量沿用历史尚未接入，不能宣称此功能已覆盖计划。

短期回执可过期，单独依赖手机随机键或本机可回滚的请求内容不足以防止旧键被改用。新增 `workout/0005_recording_v2_fence.up.sql`：成功写入和请求键的专用 HMAC 摘要在同一事务提交；回执清除后，同一主体在任何格式 2 写路由复用旧键均拒绝。瞬时失败会回滚摘要，原请求可重试；缺迁移或缺查询权限时启动失败。摘要及其派生根密钥必须与数据库一致备份，密钥轮换、恢复、生命周期与容量监控仍需运维方案。

已验证：训练组件及客户端测试、类型检查；Go `test -race ./...`（依赖专用数据库的用例无测试 DSN 时跳过）；109 项静态合同检查。腾讯云上专属 Docker MySQL 容器为 `network=none`，仅使用合成账户：先复现回执清除后旧键可再次进入执行，再验证同键不同正文、不同路由均被拒绝，失败事务可重试；缺迁移时启动失败，追加迁移后事务与真实 HTTP 流程通过。独立进程的业务装配、受保护代理入口及合成邮箱挑战分别通过私有 MySQL/Redis 测试；两个测试共享限流实例时曾使第二项返回 503，清空该本轮专用实例并单测后通过。合成备份恢复验证了加密组、移除快照和防重记录。未向公网暴露测试服务。

同一动作在一次训练中分成多段时，服务端合并活动段的累计，完成页保留各段数值并在最后显示动作合计；缺项组不算作零，移除的组和动作段不计入。训练组件及响应校验、Go 竞态测试与隔离 HTTP/MySQL 用例覆盖重复动作、缺项及移除。当前只在单次自由记录内用自定义动作名称识别，跨训练报告和改名关联仍须稳定动作库身份，不能当作已实现。

日期修正在同一版本事务中更新会话日期及训练快照：未来日期、其他账号、旧版本被拒绝，相同日期不产生新版本，回执可安全重放。离线、请求发送中、响应丢失后改日期及两份合成本地存储产生冲突均有客户端回归。实际 MySQL/HTTP 测试通过，测试环境与真实用户数据隔离。 页面回归还验证：已完成记录的最后一组移除后，留在当前页面时也会安排同步，云端变为可恢复的草稿。

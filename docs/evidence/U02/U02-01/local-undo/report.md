# 本机未提交组的移除与恢复候选

2026-11-15；范围为当前工作区尚未提交的 U02-01 部分实现，未通过任务最终验收。

- 组卡按已选“嵌入滑轨”左滑显示移除，长按可显示同一操作；滑开时组号和数值保持可读。移除后可通过底部提示撤销，也可在对应动作下展开“已移除”逐组恢复；恢复保留数值、原稳定序号和相对位置，屏幕上的组号重新顺排。
- 组卡复制会在同一动作末尾生成独立的新组，带入原有输入并保持待记录；两组拥有不同的稳定标识。合成组件检查点击复制后出现两组相同数值，重开草稿的逻辑测试验证新组仍独立存在。[内部检查图](copy-webkit.png)并非真实记录或真机截图。
- 本机草稿采用独立的版本 2 信封，包含未提交组的恢复快照；版本 1 可读取并在下一次写入升级。已提交或正在提交的组仍受原有保护，不能用此本机操作假装已经删除。服务端读取不会覆盖本机恢复快照。
- iOS 和 Android 原生草稿存储候选拒绝版本 2 降写为版本 1；iOS 在旧实现与合成存储上另验了旧版本无法读取或覆盖版本 2 的内容。该保护尚未在真机、真实 Keychain 或 Android 加密存储验证。
- 训练模块全部 Node 测试、客户端类型检查、uni-app 5.33 的 App 和微信资源编译在隔离任务工作树通过；训练模块测试在集成工作区复跑通过。两工作区 `apps/client/src` 经 `diff -qr` 比较一致。集成工作区的 `pnpm` 命令因本机依赖树版本不符，尝试重新安装时被非交互保护中止；未重新安装或清理依赖，类型检查和资源编译结果来自 5.33 任务工作树。
- [滑开状态](swipe-rail-webkit.png) 和 [撤销状态](undo-webkit.png) 由本机 WebKit 使用合成内存数据检查，非用户训练、安装包或真机截图。组件探针及测试覆盖滑开、移除、撤销、展开列表恢复；[脚本](qa-swipe-webkit.swift) 依赖本轮临时夹具与本机端口，不能单独作为发布证据。
- [iOS 候选测试](../../../P02/P02-07/draft-schema-v2-tests.swift)、[iOS 旧版读取测试](../../../P02/P02-07/old-reader-schema-tests.swift) 和 [Android JVM 候选测试](../../../P02/P02-08/draft-schema-v2-tests.kt) 使用合成数据和注入存储；iOS arm64 类型检查通过。Android JVM 不验证真实 Android JSON 运行时或设备存储。

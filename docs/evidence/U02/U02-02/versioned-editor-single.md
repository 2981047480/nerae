# App 版本化训练草稿 · 2026-11-05

## 目标与实现

App 的两种记录方式继续共用一份账号隔离的训练草稿。当前 App 工厂将 iOS／Android 的版本读取和条件写入接到编辑器：同一草稿每次只存在一笔待确认的本机写入；结果未知时保留该写入的原始前后状态，先核对，再保存其后输入。旧的 JS 无条件写入口对版本化存储关闭。

## 验证

在 5.33 隔离源码候选中执行编辑器、旧草稿存储、受保护存储与 App 工厂定向测试；另有独立复核，覆盖快速输入、创建结果不明后重开、写入结果不明和多次读取失败、恢复期间切账号、容量超限后修正及外部版本变化。版本化编辑器 10 项反例与正常路径通过；客户端类型检查、App 和微信小程序资源编译通过。合成原生端口和注入延迟用于验证 JS 协调逻辑，不代表真实 Keychain／Keystore 或设备。

## 边界

- 确认本机保存前，最新输入可能只在进程内；进程结束后不能保证恢复。
- 底层旧 UTS 无条件写接口仍存在；当前 App 工厂不调用它，旧程序或其他调用者、跨进程并发未验收。
- 微信小程序尚无可用安全草稿实现；没有真实账号接入或设备验证。
- 这不是云端同步：发送、服务端回执结算、冲突处理和真机验证尚未完成。

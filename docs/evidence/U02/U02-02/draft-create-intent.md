# 自由训练创建意图暂存 · 2026-11-05

## 范围

版本化 App 草稿编辑器可以在同一草稿内暂存自由训练创建请求的原文及账号；写入前核对当前账号、登录会话、凭据、事件、日期与时区。普通编辑不能变更待发标记、创建日期或服务端绑定，其他输入仍可继续保存。写入结果不明确时先核对原写入；完整信封超出容量时不会安装新标记。相同请求可重开确认，已有不同或无法识别的标记不会被替换。

## 验证与边界

- 编辑器、记录投影、请求／回执、草稿存储和控制器测试使用合成端口；覆盖同账号重新登录、不同账号、凭据更换、保存中暂存、未知写入、容量、连续输入和普通编辑篡改。客户端类型检查及 5.33 App／微信资源编译通过。
- 此能力没有连接页面或网络：ready 标记和本地暂存成功都不是发送许可，也不是云端保存结果。首次发送、未发送／已发送的崩溃恢复、回执结算、取消与冲突处理尚未实现。
- iOS／Android 原生旧无条件写仍存在，可能保留标记同时改变日期；未来发送前仍须重新核对账号、凭据、请求和完整草稿。跨进程、真实 Keychain／Keystore 与真机未验证；小程序受保护草稿仍不可用。
- 已准备请求在进程内保留凭据一致性比较，发送消费或发现凭据变化后释放；后续页面应在退出时丢弃未使用的请求引用，不能把其对象或比较器持久化。

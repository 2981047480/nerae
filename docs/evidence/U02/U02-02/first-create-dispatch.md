# 自由训练首次发送候选 · 2026-11-05

2026-11-06 更新：本页记录的单次发送路径保留为历史候选；创建请求的新恢复方向见 [原请求重试](create-retry-sync.md)。两者尚未连接页面。

## 范围

自由训练创建协调器先确认同账号版本化草稿中的精确创建意图、待发日志和原生首次发送标记，再调用对应的 `RecordingApi`。发送前再次检查草稿、登录凭据、原始请求和许可有效期。有效响应只返回进程内回执候选，待发日志保持待核对；它不清除草稿标记，也不将记录标为已同步。

首次发送标记已落盘后，若调用网络前读取日志暂时失败，协调器可在同一进程内持有未消费的许可继续核对；并发重试、切号及许可过期均不能多次发送。只有尚未进入发送回调的读取失败可走这条路径；回调或请求开始后失败仍需核对。这个重试能力不跨进程保存。

- `python3 -B docs/evidence/A04/A04-09/mysql_smoke.py`：私有 MySQL、回环 TLS、真实 Go HTTP 与客户端协调器联测通过。正常创建后，另一合成会话可读取同一训练；模拟服务端提交后响应丢失，另一合成会话通过只读 replay 查到回执，草稿和日志仍保留待核对状态。原生草稿和日志端口为内存夹具，并非手机或实际设备密钥。
- 独立复核测试了发送前暂时读失败、并发重试、切号和过期，未发现同进程重复发送反例。测试不证明真实设备或跨进程行为。

## 未完成

本协调器未连接页面。若进程在首次发送标记落盘后退出，客户端无法从标记单独判断网络请求是否发生；现有只读 replay 在未提交或回执过期时无法解决该歧义。还需持久回执与草稿的可恢复结算、设备间冲突处理、组保存和完成的可靠发送，才能实现真实同步。iOS／Android 真机存储及小程序受保护存储均未在本次验证。

# 云端训练恢复到本机草稿 · 2026-11-06

## 范围

新增内部恢复协调器：使用绑定当前账号、登录会话和令牌的真实 `RecordingApi` 读取训练详情，按服务端记录的时区校验日期。只有本机受保护存储和进程内编辑槽都为空时，才原子创建草稿并交给编辑器；已有草稿或内存中保留的未保存输入均不覆盖。账号或令牌变化时停止恢复，已取得的编辑器会先关闭。原生写入结果不明时保留为待核对，不假称成功。

服务端快照只表示读取时的状态；在其他设备可能继续修改的情况下，后续写入必须先取得当前服务端版本并处理冲突。恢复快照不是写入回执，也不能据此结算待发记录。

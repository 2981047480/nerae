# 自由训练创建：原请求重试与草稿确认 · 2026-11-06

## 范围与决定

自由训练创建将固定的请求键和请求正文保存在版本化草稿中。断线、响应丢失或同一账号重新登录后，重新使用原键和正文；同进程重复点击不会并发启动另一请求。服务端确认一个空白的新训练后，在同一次本机版本化写入中保存服务端标识并清除待发标记，保留等待期间新增的动作与组。创建请求返回的若是已经有其他数据的较新快照，保留本机输入并要求核对。

该方案替代早期只允许网络发送一次的创建候选：一次性标记在真正调用网络前遇到异常或进程退出时，无法判断请求是否发出，可能让记录一直无法继续。创建重试依赖服务端当前的 `(user_id, client_event_id)` 唯一约束和原始创建内容摘要；若未来允许硬删除训练或维护清理，必须先保证同一事件不能因此被错误重建。其他类型请求不能仅凭这条创建规则推断安全。

iOS/Android 的旧无版本草稿写入桥现在拒绝写入；当前 App 已使用的版本化接口不变。这样旧调用者不能在待发标记清除后，用过期整份草稿覆盖确认结果。草稿与待发请求仍属于同一账号，切号或令牌变化不接受旧回执。

- `node --import ./docs/evidence/P02/P02-11/node-ts-loader.mjs --test apps/client/src/features/training/*.test.mjs`：319 项通过。覆盖响应丢失后同账号重登与原键重试、重复点击、网络期间编辑、令牌与账号变化、伪造回执及本机确认写失败。客户端类型检查通过。
- 私有 MySQL／回环 TLS 联测运行 `python3 -B docs/evidence/A04/A04-09/mysql_smoke.py` 通过：服务端提交创建后模拟响应丢失，另一合成会话用相同键与正文恢复，数据库核实只有一条训练；另一合成会话也将服务器记录恢复到其独立本机草稿夹具。组记录与完成请求在回执过期后使用原键和正文重提，均以旧版本冲突停止，记录内容及时间未改变。原生本机存储为合成端口。[服务端记录](../../A04/A04-09/report.md)
- iOS Swift 合成后端、iPhoneOS arm64 类型检查、Android Kotlin 版本化草稿合成测试、uni-app 5.33 App 与微信资源构建通过。它们不是签名安装包，也不证明 Keychain、Keystore 或设备断电行为。
- 独立只读复核未发现账号切换、普通并发编辑或篡改请求导致误报创建成功的反例。未确认的本机写入在进程退出时仍可能丢失尚未落盘的输入。

## 未完成

该协调器尚未连接训练页面，也没有提交动作组或完成训练。组记录和完成需要各自的持久请求、响应合并、冲突恢复和页面接线。小程序的受保护草稿仍不可用，线上服务、真实两设备、iOS 安装与真机尚未验收；不能将创建成功称为训练记录已同步。

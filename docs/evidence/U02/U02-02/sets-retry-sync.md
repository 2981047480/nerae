# 训练组：持久请求、回执与并发输入 · 2026-11-06

训练后记录提交有效组的批次；逐组记录只提交用户确认的那一组。发送前将固定正文、重试键和当时的输入一起写入同一份受保护草稿。断线后若服务端版本未变，原键原文重试；版本已变时仅读取原请求的历史回执。确认后在同一次本机版本化写入中更新服务端版本、确认已保存的组并清除待发标记；等待期间继续修改的输入和新增的组会保留，正在提交的组不能删除。

服务端版本变化且原回执不可用时，保留原草稿并要求核对，不以新版本盲目重发。单份受保护草稿上限为 64 KiB；待发请求超过容量时拒绝发送且保留原输入，尚未实现大批次拆分。设备存储写入失败时，未写入的最新内容可能仅在进程内，不能声称已持久保存。

# A01-07 登录响应所需会话资料

新增内部会话资料读取：使用已提交的令牌在新事务中复核身份、账号、设备与会话，从同一主体读取当前昵称、成年本人声明和有效角色；未设置昵称返回空字符串，未配置角色返回空列表，不推断资料或 onboarding 状态。资料和令牌有效期不是后续业务授权，业务请求仍须重新鉴权。

响应准备以签名令牌的绝对过期时间计算剩余秒数并向下取整；同一令牌重试不能重新获得完整初始时长。资料对象不含令牌，默认格式化和 JSON 序列化均不输出资料。事务内复验跨过过期时间时明确返回失效，存储异常仍返回不可用。

## 验证

`python3 -B docs/evidence/A01/A01-07/mysql_smoke.py` 在仅 Unix socket 私有 MySQL 上通过 Go race，退出 0。覆盖新用户空资料、当前昵称和有效角色、成年声明、不同时间的剩余有效期、账号禁用、会话撤销、到期、事务内复验过期、脱敏，以及实际等待账号锁后读取更新后的昵称与角色。

首次运行中测试直接把会话改为 revoked 而未写 revoked_at，触发数据库状态约束；修正测试以符合真实迁移后复测通过。失败的合成数据库目录 `/private/tmp/nerae-auth-session-mysql-a6lwhha1` 未删除。

## 限制

这是内部资料投影，尚未装配登录 HTTP；接口响应语义、限流、真实邮件、客户端实际调用及双设备流程仍须单独接线验证。

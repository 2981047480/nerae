# A01-07 已认证会话回执重放

## 范围

`ReceiptRecoverer` 在原事务中重新匹配完整请求摘要、原设备签名和回执；解密前按身份、用户、设备、会话顺序加锁，核对当前邮箱身份、设备指纹、挑战、主体状态、会话版本和有效期。解密后验证签名令牌并再次检查授权。事务结束后 `ReceiptCandidate.AfterCommit` 在新事务重读已提交回执、重验设备证明和当前授权，再于提交后检查令牌、回执和设备证明时效。候选结果本身不能序列化或输出令牌。

## 验证

`GOFLAGS='-run=^TestSessionReceiptRecovery$' python3 -B docs/evidence/A01/A01-07/mysql_smoke.py` 和完整脚本均退出 0，分别使用新建仅 Unix socket 的私有 MySQL 和 Go race；加载本任务所需 6 项迁移。覆盖提交前不释放、原令牌恢复、回滚、变更验证码或事务、账号停用、身份/设备/会话撤销、版本变化、回执过期、密文篡改和上下文失败。实际持有用户行锁后并发停用账号，重放等待锁释放并拒绝令牌。可控时钟在多个阶段推进，验证会话、回执及设备证明到期后不释放令牌；该时钟测试不模拟实际慢提交。

独立只读复核指出最终证明复验可能跨过会话期限；已在其后重新认证并在提交后再次核对时效。复核通过后又补充提交后原证明的密码学和时间检查，定向与完整隔离测试均重跑通过。

## 限制

该能力尚未接入邮箱登录协调器、HTTP、限流、真实 SMTP 或手机。它仅恢复会话令牌，完整 HTTP 响应的用户资料与有效期呈现仍需按合同确定；新设备审批回执和批准兑换的安全重放尚未实现。检查提交后立即发生的撤销不能阻止已返回的令牌，后续请求仍须由服务端重新鉴权。跨实例时钟偏差、真实邮件与设备均未测试。

# A01-07 会话凭据事务内加密

## 范围

新增 `Issued.SealForReceipt`：只接受原签发事务中的有效邮箱证明，复查会话、用户、登录身份、设备、挑战关联与时效，将会话令牌加密为不透明回执并返回非凭据会话引用。调用方必须从原请求生成摘要，在同一事务持久化密文；密文不证明事务已提交，不能直接发给客户端。

## 验证

`GOFLAGS='-run=^TestEmailSessionLifecycle$' python3 -B docs/evidence/A01/A01-07/mysql_smoke.py` 与不带过滤条件的同一脚本分别退出 0；每次使用新建的仅 Unix socket 私有 MySQL 和 Go race。覆盖不同事务、错误挑战、同事务撤销设备、改变邮箱身份索引、密文不含令牌、事务回滚与结束后拒绝再次封装。测试在实际提交后重新验证原设备签名和活动会话，再核对密文可还原为已签发令牌；这不是登录协调器的重放实现。

## 限制

调用方目前自行保证摘要来自同一次实际登录请求；尚未把封装结果写入登录回执仓储，也未实现以会话引用先验授权、提交确认未知恢复、批准秘密回执、生产 HTTP 或真实发信。不能将加密成功或独立测试称为真实登录、跨设备同步或真机验收。

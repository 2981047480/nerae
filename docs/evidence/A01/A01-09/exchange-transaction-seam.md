# 新设备兑换与回执的事务接缝

2026-11-03，本批只验证内部事务，尚不提供可用的新设备兑换接口。

- 兑换内部接缝返回包内私有、禁止 JSON 序列化和脱敏输出的候选；公开 `Exchange` 保留提交成功后返回令牌的现有边界。
- 候选在所属事务内从原始申请、密钥、设备证明和待发会话推导加密回执绑定；同一事务中可持久化审批消费、设备与会话、证明防重标记和回执。回执写入后必须重新检查申请、来源会话与设备证明的时效及已消费标记。
- 隔离 MySQL 与 Go race 测试验证手工组合的提交和显式回滚、回执写入失败、错误请求绑定、分别到期的审批和设备证明，以及回滚后使用同一证明重试。测试只使用合成账号及设备，不连接线上数据。

验证命令：`python3 -B docs/evidence/A01/A01-09/mysql_smoke.py`。脚本使用独立 MySQL socket、临时合成数据库和 `go test -race`；通过后移除该脚本自行创建的测试目录。

限制：回执组合目前由测试代码调用，尚无正式事务协调器；包内代码仍能访问私有候选字段，封装本身不构成提交后释放保证。到期测试使用注入时钟，未模拟候选最终复核期间真实锁等待，也未验收应用时钟与数据库时钟偏差。精确重试必须重新核验原设备证明、JTI、审批和来源会话及目标会话的当前授权，并在提交后的新事务复核后才释放令牌。公开 HTTP、限流、原生设备、真实双设备和部署均未完成。

# 新设备审批状态及幂等快照

2026-11-03，内部 `PollExchanger` 验证申请 secret、服务端保存的设备公钥、签名的 nonce/申请 ID/JTI、身份和主体当前状态。等待、拒绝、过期只返回无凭据状态；状态快照与证明的单次消费同事务提交。批准或已消费状态交由 `ReceiptExchanger` 执行其加密会话回执与提交后授权复核。

同一键和完全相同请求只重放首次非认证状态；状态变化后由 App 生成新随机键与新签名继续查询。曾为等待状态的请求在批准后重试仍返回等待快照，避免同一幂等键改变结果；新请求方可领取会话。失效证明、失效主体、原证明换键和错误 secret 均不返回状态或凭据。已消费审批即使过期也不另建与成功回执竞争的状态回执。

验证：`python3 -B docs/evidence/A01/A01-09/mysql_smoke.py` 在 socket-only 隔离 MySQL 执行 `go test -race`，覆盖等待/拒绝/过期/批准、原快照与新查询、错请求、单次证明、并发、主体禁用、回执写失败、成功提交后确认丢失、proof epoch 锁等待时审批或证明过期回滚、丢失 key epoch 但保留历史拒绝初始化。`go run ../../scripts/dev/migrate.go check` 校验 18 项迁移清单。故障注入在真实本机 MySQL 成功 COMMIT 后模拟确认失败，不是实际网络断连。

后续进度：独立匿名限流与未挂载 HTTP handler 已实现并在隔离 MySQL、Redis 和本机 TLS 同链测试；具体范围见 [exchange-http.md](exchange-http.md)。实际 API 路由装配、真实代理来源 IP、保留记录清理和客户端轮询仍待完成。不能对公网开放；应用与数据库时钟偏差未验收。成功会话提交后，若原证明过期或来源会话撤销，结果可能无法重取且已提交目标会话保留。真实服务和双真机尚未测试。

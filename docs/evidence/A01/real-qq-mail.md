# QQ 邮箱真实发信与本机登录联测

2026-11-03，用户在本机提供 QQ 邮箱授权码和发件地址。敏感配置文件已确认受 Git 忽略，并限制为文件所有者读写；邮箱地址、授权码和验证码均未写入证据或命令输出。

首先使用项目的 SMTP 传输组件，通过 TLS 将一封测试验证码邮件发送到同一个发件邮箱。QQ SMTP 接受投递，用户随后确认实际收到；该邮件不是有效的 Nerae 登录挑战。

随后使用新建的本机私有 socket MySQL/Redis、临时随机数据保护密钥、合成 P-256 设备密钥和回环 TLS 处理器，执行真实邮件登录链路：创建邮箱挑战、发信队列提交 QQ SMTP、服务器接受、用测试程序从同一挑战派生的验证码调用邮箱登录，再通过 `/me` 读取已认证会话。该测试退出 0，测试数据库及服务正常关闭并移除。测试程序没有从收到的第二封邮件中读取验证码，因此该次登录验证不等于用户手工输入邮件验证码的验收。

验证使用临时测试程序和临时数据库；没有更改腾讯云服务器、部署服务、创建线上账号或安装 App。实际手机交互、新设备可靠兑换、跨设备同步、服务端 HTTPS 和生产凭据管理仍未完成。SMTP 接受本身也不能保证任意其他收件人的实际送达。

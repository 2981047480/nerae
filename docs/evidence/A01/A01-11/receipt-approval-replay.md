# A01-11 新设备待批准回执接线

## 范围

邮箱登录首次创建新设备待批准申请时，将申请和加密回执同事务持久化；同幂等键、完全相同的重试恢复原轮询凭据。提交后重新校验原设备证明、身份、账号、申请及有效期，不为新设备签发会话。已有可信设备明确批准后，仍可恢复原轮询结果；真正的兑换由单独流程处理。

## 验证

定向与完整 `docs/evidence/A01/A01-11/mysql_smoke.py` 在新建仅 Unix socket 私有 MySQL 上通过 Go race，退出 0。覆盖首次申请、相同请求重试、并发重试返回同一申请 ID 与秘密且数据库只有一份申请、可信设备明确批准、已批准后的轮询恢复，以及批准前后未通过本路径创建新设备会话。设备撤销、过期、已兑换与锁等待的组件级证据见 [申请回执重放](../A01-08/approval-receipt-replay.md)。

## 限制

错误验证码回执仍不可重放；批准兑换的幂等、HTTP、限流、真实 SMTP、生产部署和双设备测试均未完成。隔离事务测试不代表真实登录或跨设备同步已经完成。

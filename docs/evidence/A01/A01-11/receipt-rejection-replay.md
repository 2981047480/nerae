# A01-11 错误验证码回执重放

## 范围

已验证设备签名但验证码错误时，尝试次数、JTI 标记和空明文加密拒绝回执同事务提交；完全相同的重试在核对原请求、签名、标记、回执密文和时效后，只返回通用拒绝，不重复计数。提交后在新事务再次检查已提交回执与证明，回滚或密文损坏不能冒充已处理；错误签名不创建回执。

## 验证

定向及完整 `docs/evidence/A01/A01-11/mysql_smoke.py` 在新建仅 Unix socket 私有 MySQL 上通过 Go race，退出 0。覆盖首次错误码提交、同键重复及并发重试、换键复用同一 JTI 不增加次数、同键不同请求冲突、回滚后无计数/回执、篡改密文不可作为有效结果；可信设备与待批准分支的回归同时通过。

独立复核发现已提交的拒绝回执过期后可能误报服务不可用。现用 `LockExisting` 区分过期、冲突与缺失：明确过期或冲突返回通用拒绝，记录缺失仍按不可用处理以避免把回滚误认为提交；对应隔离数据库测试通过，过期查询不删除回执。

后续复核发现回滚后若立即重发验证码，旧槽位换绑会让缺失回执被误判为冲突。`LockExisting` 已区分槽位换绑和原回执缺失；定向测试先回滚错误码事务，再发新验证码，原候选仍返回不可用，次数及回执均未留下。定向和完整隔离数据库回归均通过。

## 限制

本能力仍是未挂载事务接口；完整 HTTP 响应、限流接线、批准兑换的幂等、真实 SMTP、生产部署与双设备测试尚未完成。

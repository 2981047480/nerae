# App 登录与设备确认入口 · 2026-11-03

App 首页已挂载既有邮箱登录及已登录设备确认组件。只有当前会话与登录结果
的主体、代次一致，且成年声明已确认，才显示已登录设备确认；本机会话变化时
立即隐藏旧界面。首页使用同一个 App runtime，保留登录尝试的既有安全取消和
重试语义。根页面不显示无法返回的“返回”按钮。
如果先前未能确认的安全取消在重试后完成，根页面会重新挂载登录组件，
避免停留在已释放的组件上。

列表读取遇到具备 no-store/JSON 保护头的 401 时，页面先撤下旧界面并提示
重新检查；重新检查调用现有 `/me` 校验，不直接根据列表响应删除凭据。403、
缓存响应及其他错误仍保持不可用。已有待决的设备确认不会触发列表请求；
确认结果未知时继续保留原操作和重试状态。

App 通过构建时公开配置 `VITE_NERAE_API_BASE` 获取 HTTPS API 地址，不提供
默认服务器或降级；缺失、非法及 HTTP 地址使登录不可用。该值会被嵌入客户端，
不得包含任何密钥。当前没有在此改动中配置实际线上地址。微信小程序和 H5
条件编译后显示该平台登录不可用，微信登录仍未实现。训练记录入口未接通，
页面明确显示暂不可用。

## 验证

- 对首页会话门禁、登录控制器、设备确认 API/控制器、App 认证组合及首页的
  43 项 Node 测试通过。首页测试编译实际 Vue 单文件组件，使用合成子组件和
  会话端口验证未配置服务、合法会话重验及撤销会话回登录，不是原生 UI 测试。
  401 恢复与旧观察者解绑的两个反例在修复前失败、修复后通过。
- `vue-tsc --noEmit -p tsconfig.json` 通过；使用本地 5.33 `uni build -p app`、
  `mp-weixin` 与 `h5` 均通过。单独使用合成 HTTPS 地址的 App 构建证明公开配置
  进入 App 资源，小程序资源未包含该地址；随后的无地址构建不含该测试地址。
- 独立只读复核发现受保护列表 401 后可能停留在旧界面；修复后复核未发现新的
  P0/P1。服务端若对列表返回 401、但 `/me` 仍认该令牌，用户手动重验后可能
  再次看到重验提示；不会自动清凭据或自动循环。

构建和合成测试不代表线上部署、真实邮件登录交互、可信双设备同步或真机视觉
验收。首页和组件尚未在 iPhone 安装或查看；Android 原生能力及小程序微信登录
仍需分别完成，不能作为用户要求的首个可安装测试版交付。

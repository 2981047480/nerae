# A01-02 登录重试证明标记复查

## 范围

新增事务内 `EnsureConsumed`：在不创建防重标记的情况下，核对设备指纹、受保护的 JTI 摘要、密钥 epoch 和标记保留期限。该方法只提供存储检查，不验证签名或授予登录；未来调用方必须在同一事务中重新验证原请求、签名、当前授权和有效期，并在锁等待后重新检查时效。

## 验证

`python3 -B docs/evidence/A01/A01-02/mysql_smoke.py` 在授权的本机隔离环境下退出 0，使用一次性、仅 Unix socket 的私有 MySQL，运行 Go race 测试。覆盖已提交标记、缺失标记、其他设备、回滚、密钥不符或缺失、保留期被缩短及微秒舍入。成功的测试目录由脚本移除。

同一脚本在普通受限沙箱中 MySQL 初始化退出 2；保留目录 `/private/tmp/nerae-proof-mysql-_uv54pkg` 的日志显示 MySQL 启动时 SIGSEGV（映射对象权限错误）。后续在授权隔离环境复跑通过；失败目录未删除。

## 限制

这不是登录重放实现，也不证明跨设备登录、凭据撤销或 HTTP 接线。标记和 epoch 同时全部丢失时，原有首次初始化机制仍不能单独识别历史丢失；生产启动、备份和密钥恢复需要独立控制。

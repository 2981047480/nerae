# 审批兑换回执的真实会话核验器

`session.Store.VerifyCurrentSession` 为已有的 `approvalreceipt.CurrentSessionVerifier` 接口提供真实实现：使用调用方同一个数据库事务验证签名，锁定并重新检查身份、用户、设备和会话，核对签名主体／会话与数据库状态，并返回分别来自签名和数据库的相等到期时间。出错时不返回主体、会话或到期信息。该方法自身不授权兑换，也不负责提交事务或向客户端释放 token。

在私有 socket MySQL 中运行 `python3 -B docs/evidence/A01/A01-07/mysql_smoke.py`，退出 0；Go race 测试用真实会话和审批回执密码组件在同一事务完成加密／解密，并验证错误 token、数据库与签名到期不一致、事务内撤销设备、等待身份锁期间会话过期。另在应用时钟落后的合成场景验证：已过数据库时间的回执不能被解密。测试不验证审批设备签名、JTI、已提交回执保存或响应丢失后的兑换。

尚需将兑换写入、JTI 消费、会话创建和加密回执存储在一个事务里，并在重放时重新核验设备证明与当前授权；提交前不得向客户端释放明文凭据。当前没有兑换 HTTP 入口、App 页面或真实设备验收。

# 邮箱登录与当前用户 HTTP 处理器

新增未挂载的邮箱登录和 `GET /me` 处理器。登录处理器校验合同 JSON、规范幂等键及注入的可信来源 IP；调用方必须提供先限流、再提交并复验的真实协调器。认证成功时通过提交后会话读取当前资料，按原令牌绝对过期时间计算剩余秒数；待批准只返回申请能力。`/me` 只从 Bearer 和实时会话读取主体，不接受客户端指定的用户 ID。成功和错误响应均为 `no-store`，错误不返回原始异常或凭据。

包级 `go test -race -count=1 ./internal/modules/auth/transport` 退出 0，覆盖恶意输入、错误脱敏、可信 IP、模拟 profile、会话失效/不可用及响应编码跨秒；未设置私有数据库和 Redis 环境的集成用例按设计跳过。独立只读复核没有剩余具体 P0–P2，但真实协调器、MySQL、Redis 和本机 TLS 的成功路径尚待同版验证。

处理器尚未挂生产路由；真实 SMTP、客户端页面、服务部署与手机测试尚未完成。

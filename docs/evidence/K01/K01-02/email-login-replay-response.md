# 邮箱登录重放响应规则

邮箱登录对完全相同请求的安全重放保留原令牌和原会话到期时间；重放时重新授权并读取当前用户资料，`expiresIn` 是响应生成时向下取整的剩余秒数。待批准结果保留原申请及绝对到期时间。由于剩余秒数与当前资料会变化，认证结果是语义重放，不保证响应正文逐字节相同；客户端不能从收到响应的时刻直接假定完整剩余期，也不能用缓存代替服务端授权。

# 邮箱登录重放响应规则

邮箱登录对完全相同请求的安全重放保留原令牌和原会话到期时间；重放时重新授权并读取当前用户资料，`expiresIn` 是响应生成时向下取整的剩余秒数。待批准结果保留原申请及绝对到期时间。由于剩余秒数与当前资料会变化，认证结果是语义重放，不保证响应正文逐字节相同；客户端不能从收到响应的时刻直接假定完整剩余期，也不能用缓存代替服务端授权。重试同样受限流，返回 429 时须保留原请求及幂等键，等待限流窗口结束并在证明和回执仍有效时重试；隔离 MySQL/Redis 测试已覆盖限流后恢复同一令牌。`GET /me` 的 200 和 401 响应要求 `Cache-Control: no-store`，以支持客户端安全恢复会话。

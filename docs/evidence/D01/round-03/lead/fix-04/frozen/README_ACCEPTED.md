## 数据与预览边界

- 固定预览日期 `2026-10-24（周六）`，本周 `10月19日–25日`；训练日为周二/周四/周六。
- 学员林澈、教练顾言、其他内容均为样例，不代表真实用户、健康评估、认证、教练服务或成交。
- 只使用本机 `localStorage`，不调用真实 AI、消息、支付、网络接口，也不发送任何外部请求（图片、图标均为本地/打包资源）。
- “预览”控制可切换角色/情境、减少动态效果、重置全部本机预览数据；重置会取消计时并回到初始状态。
- 浏览器刷新会恢复训练进度、未提交输入、休息倒计时、收藏、训练/饮食各自筛选和教练草稿；这是本机持久化，不是服务器同步。
- 存储不可用时保留内存输入，明确提示“未能保存到本机”并提供重试；不会显示虚假保存成功。
- 文字大小 100%/200% 是预览检查入口，用根字号与 rem token 放大正文/控件文字，不做整体 transform；刷新保留，重置回 100%，与 Reduce Motion 独立。它不是系统动态字体、微信字体设置或真机验证。
- 教练内容变化保存才产生新草稿版本；无改动保存不增版。已交付版本保存不可变快照，后续编辑只影响新草稿，学员现用版本保持 6，直到采用流程（未实现）。
- 训练事件时间使用固定预览会话时间线递增，休息倒计时按真实经过时间计算；新记录不会出现在样例时间之前。
